## 7. Rules that bite on this template (condensed — the playbook is authoritative)

- **Never delete an unused component variant.** It is inventory for the next brand.
- **Only docx content may produce a heading.** Chrome (navbar, footer, ticker,
  winners feed, login widget, card labels) uses `<p>`/`<span>` + `aria-label`.
  One `<h1>` per page, ever.
- **No HTML comments** (`<!-- ... -->`) in anything that renders — Astro ships
  them verbatim. Put notes in the frontmatter (`//`) instead. Strip existing
  ones from any rendered component you rewrite.
- **Body copy** is `text-left text-base leading-relaxed <colour>` on the element
  carrying the slot. No `mx-auto max-w-4xl` on page `<p>`s.
- **`<strong>` highlight colour is `#fae474`**, and each `<strong>` must wrap a
  whole space-delimited chunk of Thai — the copy must read identically with the
  tags removed.
- **Never write `isActive` by hand** in a navbar — import `isActivePath` from
  `../lib/nav`.
- **Never use `define:vars`** / an attribute-less `<script>` on an indexable page.
- **Emoji needs `aria-hidden="true"`** on its own `<span>`, never inside label text.
- **No `href="#"`, no `onclick=`.**
- **`alt` describes the picture**, not a counter.
- **JSON-LD only via `pageGraph()`** from `src/lib/schema.ts`. Never type a
  domain, never `Astro.url.origin + path`. No `Review` / `AggregateRating` /
  `sameAs` / `address` nodes.
- **Meta descriptions you write yourself: 150–160 characters** (count chars, not
  bytes). The home page uses the brief's 126-char line verbatim and is exempt.
- **`/contact-us`, `/ทางเข้า`, `/promotion`, `/login`, `/register` carry NO
  `<h2>` and no article prose** — h1 + buttons (and, on `/promotion`, one ~4-line
  intro paragraph + the image grid). If the page you inherit has headings and
  paragraphs, delete them.
- **`ContentBoxSevenThree*` is capped at 2 for the whole rebrand.** Both are
  spent on index (H3 #4 and H3 #5). No other page may add one.
- **`slide*` images appear ONLY inside a `ContentBoxSevenThree*` block** — with
  the single documented exception of `/promotion`'s own image grid.
- **Do NOT run `npm run build`.** The orchestrator runs the single build in
  Phase 5.
