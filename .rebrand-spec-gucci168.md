## §9 Hard rules that fail the build

- No HTML comments (`<!-- -->`) in anything that renders — Astro ships them.
  Frontmatter `//` comments are fine and are stripped.
- Exactly one `<h1>` per page. Chrome may not take a heading tag at any level.
- Decorative emoji live in their own `<span aria-hidden="true">`, never inside
  the label's text.
- `alt` must describe the picture. No `href="#"`, no `onclick=`.
- No `define:vars`, no `is:inline` script on an indexable page.
- JSON-LD only via `pageGraph()`. No `Review` / `AggregateRating` / `sameAs` /
  `address` / `PostalAddress` / `email` nodes. No domain typed out, no URL built
  with `+`.
- Paragraphs: no `mx-auto`, no `max-w-*` — the card caps its own width.
  No colour class on paragraphs either; they inherit `#f6e3cf` from the card.
- One element per slot.
- **Never delete an unused component variant** — it is inventory for the next brand.
