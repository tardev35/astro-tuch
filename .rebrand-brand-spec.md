## §2 Palette

Measured from `src/assets/palette.json` + reading the artwork. The brand is a
**two-colour pair**: bright sky blue leads, lemon yellow is a genuine second
hue (the logo is Thai lettering `แตกดี` in flat lemon yellow stacked over `168`
in flat sky blue). The artwork is bright/kawaii — sky, clouds, gold coins,
a silver-haired character in blue-and-white — but `src/assets/bg.json` is
`{"mode":"color","color":"#000000"}` and `MainLayout`'s global block sets
`background-color: #000000`, so **the page surface stays dark**. Cards are a
deep navy-black ladder so the bright hues read as neon against them.

## §7 Standing rules that bite on this run

1. **Never delete an unused component variant.** The inventory is for the
   next brand. Old brand names and colours inside a file nothing renders are
   expected drift, not bugs.
2. **No HTML comments (`<!-- … -->`) in anything that renders.** Astro ships
   them verbatim. Strip them from every rendered component in the same pass.
   Frontmatter `//` comments are fine and are where notes belong.
3. **Chrome may not take a heading tag, at any level.** Ticker, winners feed,
   nav, footer, card labels, badges, RTP widget, review cards → `<p>`/`<span>`
   with the same classes + `aria-label` on the container.
4. **One element per slot.** Wrap multiple blocks in a single `<div>` yourself.
5. **Body copy is `text-left text-base leading-relaxed`** on the element
   carrying the slot. No `text-sm`/`text-lg` prose, no `mx-auto max-w-*` on a
   page-level `<p>`.
6. **Do not re-add a slot wrapper `<div>`** to a flattened ContentBox variant,
   and keep `isolate` on the card + `-z-10` on decorative layers.
7. **Decorative emoji live in their own `<span aria-hidden="true">`,** sibling
   to the label, never inside the text, never leading an announcement message.
8. **`alt` describes the picture** (see §4). Decorative repeats get `alt=""`
   plus `aria-hidden` on the wrapper.
9. **Navbars import `isActivePath` from `../lib/nav`** — never hand-roll
   `isActive`. Feeds use `src/lib/winnersFeed.ts`; no `define:vars` on an
   indexable page; no Swiper.
10. **JSON-LD only via `pageGraph()`.** No typed domains, no `+`-built URLs,
    no `Review`/`AggregateRating`/`sameAs`/`address`/`PostalAddress`/`email`.
11. **Keep `color: ${BRAND_TEXT}` in `MainLayout`'s `<html>` style attribute.**
12. **Do not run `npm run build`** unless you are the orchestrator in Phase 5.
13. Do not touch `src/styles/_sources.generated.css` (build artifact) or
    `workspec.md` (frozen history).
