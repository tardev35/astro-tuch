## §6 Rules that are easy to break this round

- **Only article content may produce a heading.** Chrome (navbar, footer,
  ticker, winners feed, review cards, login/RTP widget, card labels) renders its
  labels as `<p>`/`<span>` with an `aria-label` on the section — never `<h1>`…`<h6>`.
- **No HTML comments** (`<!-- … -->`) in any rendered page or component — Astro
  ships them verbatim. Strip them while rethemeing. Frontmatter `//` comments are
  fine and are stripped.
- **House body-copy style**: the element carrying a slot gets
  `text-left text-base leading-relaxed text-[#ece2f8]`. No `text-sm`, no
  `text-lg` for prose, no `mx-auto`/`max-w-*` on a `<p>` in a page.
- **One element per slot.** Two paragraphs → wrap them in a single
  `<div class="flex flex-col gap-4">`.
- `<strong>` wraps a whole space-delimited chunk of the brief's sentence (Thai
  has no inter-word space); never two adjacent `<strong>`s. One highlight colour
  only: `#ffd45e`.
- **`isActivePath` from `src/lib/nav`** — never hand-write `isActive` in a navbar.
- **No `define:vars`**, no empty JS-filled feed container, no unguarded timers,
  no Swiper.
- **Emoji** must sit in an `aria-hidden="true"` element, as a **sibling** of the
  label text, never inside it. No emoji at the start of an announcement message.
- **No `href="#"`, no `onclick=`.** Back-to-top is `<a href="#top">`.
- **`alt` describes the picture** (see §4).
- **JSON-LD only via `pageGraph()`**. Never type a domain, never build a URL with
  `+`, never add `Review` / `AggregateRating` / `sameAs` / `address` / `email`.
- **`<Image>`/`<Picture>` always get `widths` + `sizes`** describing how wide the
  image is **drawn**. Keep `quality={80}`; `tools/avif-quality-service.mjs`
  rescales AVIF on its own.
- Keep `color: ${BRAND_TEXT}` in `MainLayout`'s `<html>` style attribute, and
  keep `?v=${iconVersion}` on every icon href.
- Do **not** re-sort `MainLayout`'s `<head>`, do **not** add a
  `google-site-verification` meta, do **not** create `public/robots.txt`.
- `BRAND_ADDRESS` derives itself from `BRAND_NAME` — never hand-write it. The
  `<address>` block is pasted **verbatim, unthemed** into the active footer.
