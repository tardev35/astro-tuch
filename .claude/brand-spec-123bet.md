| ค่า | ค่าที่ใช้ | ที่มา |
|---|---|---|

| worker name | `123bet-play` | `SITE.hostname.split(".")[0]` |

⚠️ **worker name ≠ iconSlug รอบนี้** (`123bet-play` vs `123bet`) — โดเมนมี `-play`
ต่อท้าย ส่วนชื่อแบรนด์ไม่มี **ที่มาคนละทางเสมอ** (name มาจากโดเมน · slug มาจากชื่อแบรนด์)
✅ ตรวจลิสต์ห้ามซ้ำใน `wrangler.toml` ทีละตัวแล้ว — ไม่มี `123bet-play`
(`dm899bet` · `up555bet` · `789betting-th` · `gucci168-play` · `koon234-play` ·

**ห้ามพิมพ์ชื่อแบรนด์เป็นตัวอักษรตรงๆ ในโค้ดทุกที่** — interpolate `${BRAND_NAME}` เสมอ

## §2 พาเลต — ธีม **สว่าง** (กลับทิศ 180° จาก ZORO365 ที่มืดทั้งเว็บ)

🚨🚨 **ทิศของรอบนี้: เนื้อหาเป็นผิวสว่าง + โครม (navbar/footer) เป็นผิวเข้มแดงเลือดหมู**
`bg.json` ของดรอปนี้ = `{"mode":"color","color":"#f7e4e9"}` = **ชมพูบลัชจาง**
รอบก่อน (ZORO365) เป็น `#002908` เขียวป่าจมเกือบดำ — **คนละปลายของสเกลความสว่าง**
`bg.json` คือแหล่งเดียวของพื้นเพจ **เปิดอ่านทุกรอบ ห้ามสืบทอดค่าข้ามรอบ**
⚠️ **ห้ามคงผิวเข้ม `#073c1a` / `#031b09` / `#002908` ของรอบก่อนไว้แม้แต่ที่เดียว**
บนธีมสว่างรอบนี้ = หลุมดำกลางหน้าสว่าง

### จุดที่ชั้น heading รั่วได้ — กันไว้ทุกจุด

- บรรทัด 15/17/19 (`ขั้นตอนที่ 1/2/3`) **ไม่มี prefix H ในบรีฟ** → ส่งเข้า
  `titleleft`/`titlecenter`/`titleright` ของ `ContentBox3ThreePremium` โดย
  **ไม่ส่ง `heading`** (default `false` → render เป็น `<p>`) **ห้ามส่ง `heading`**
- `ContentBoxTwo` / `ContentBoxSevenThree*` — **ไม่ส่ง `titleright`** คอลัมน์ภาพ
  จึงไม่มี heading
- `ContentBoxSpecial` — ส่ง `as="h2"` ชัดเจน
- `Faq4` — default `as` เป็น `"p"` **ต้องส่ง `as="h2"` ชัดเจน** และคำถามแต่ละข้อ
  เป็น `<span>` ใน `<summary>` ไม่ใช่ heading
- chrome (`Announcement5` · `ProviderGrid` · `LatestWinners2` · `ReviewCardSumo2` ·
  `Navfoot` · navbar · footer) ขึ้นป้ายเป็น `<p>`/`<span>` + `aria-label` บน
  `<section>` **ห้ามเลื่อนขึ้นเป็น heading เพื่อ "แก้ชื่อที่ขาด"**
- ก่อนจบ ให้ `grep -n '<h[1-6]' ` ทุก component ที่หน้านั้น render จริง —
  ทุกแท็ก heading ต้องมาจาก prop (= มาจากบรีฟ) **ห้ามมี heading ที่ hardcode ข้อความไทย**

## §7 สถานะหน้าเว็บ

### หน้าหวย — **ปิดต่อไป** (ไม่มีอะไรต้องย้าย)

บรีฟเรียกตัวเองว่า **"เจ้าของบาคาร่าสล็อต"** และ `หวยออนไลน์` เป็นเพียง
**หนึ่งในเจ็ดหมวดเกม** · บรีฟไม่มีคำว่า `สลาก` `งวด` `เลขเด็ด` `ลอตโต้` `โพย`
`รอบปิดรับ` เลยสักคำ
→ `ตรวจหวย.astro` + `แนวทาง.astro` **อยู่ใน `src/pages-disabled/` ต่อไป**
→ `NavbarPremium` + `FooterPremiumSumo` **ต้องไม่มีลิงก์ `/ตรวจหวย` หรือ `/แนวทาง`**
(ลิงก์ที่ชี้ไป route ที่ไม่มีจริงจะทำให้ `verify-build` แดง)

### หน้าที่ routed อยู่ (11 route) — **ทุกหน้าอยู่ในสโคปรีแบรนด์**

`index` · `about-us` · `contact-us` · `login` · `privacy` · `promotion` ·
`register` · `terms` · `ทดลองเล่น` · `ทางเข้า` · `404`

- **ไม่มีหน้าไหนมี `TODO(rebrand)`** → รอบนี้ uploader ไม่ได้ scaffold หน้าใหม่
- `about-us` เปิดอยู่และมีเนื้อหาจริงของรอบก่อน → **รีแบรนด์เต็ม ไม่ต้อง park**
- `src/pages-disabled/about-us.astro` เป็นสำเนาเก่าของ **JEDI66** — **ไม่ต้องแตะ**

### toggle CTA เปิดอยู่

`login.astro` / `register.astro` เป็น **หน้าปุ่มจริง** (มี `const targetUrl`)
→ เมนู navbar มี `สมัครสมาชิก` + `เข้าสู่ระบบ` ถัดจาก `โปรโมชั่น` ทันที
→ `/ทางเข้า` **ถูกถอดออกจากเมนู** (route ยังมีอยู่ footer ยังลิงก์ได้)
→ **ห้ามแก้ `targetUrl`** (`https://yoalink.com/hx8w`) — เป็นลิงก์ affiliate ของแบรนด์นี้

### ลำดับเมนู navbar (7 รายการ พร้อมไอคอนทุกรายการ)

```
หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · ทดลองเล่น · เกี่ยวกับเรา · ติดต่อเรา
```

ไอคอนต้องเป็น `<span aria-hidden="true">` ที่เป็น **พี่น้อง** ของ label
**ห้ามต่อไอคอนเข้าไปในข้อความของ label** และ **ห้ามแยก links เป็นสองอาร์เรย์**

### หน้าที่ **ห้ามมี `<h2>` และห้ามมีย่อหน้าอธิบาย**

- `/contact-us` → `h1×1 h2×0 h3×0` (title + รูป LINE + บล็อกที่อยู่ + แถวปุ่ม)
- `/ทางเข้า` → `h1×1 h2×0 h3×0` (title + กริดปุ่มสองช่อง)
- `/promotion` → `h1×1 h2×0 h3×0` (title + **intro ย่อหน้าเดียวประมาณ 4 บรรทัด**
  + กริดรูป slide1/slide2 + ปุ่มสมัคร)
- `/login` `/register` → `h1×1 h2×0 h3×0` (title + ปุ่มเดียว)

บรีฟมีแค่ `Title`/`Meta` ให้หน้าเหล่านี้ **ไม่เคยมี body** — ย่อหน้าที่เจอในไฟล์
คือของที่รอบก่อนคิดขึ้นเอง **ลบทิ้ง นั่นคือการแก้ ไม่ใช่การเกินสโคป**

## §8 กฎที่ subagent ทุกตัวต้องถือ

1. **ห้ามรัน `npm run build`** — build เดียวของทั้งรอบอยู่ที่ orchestrator (Phase 5)
2. **ห้ามลบไฟล์ variant ที่ไม่ได้ใช้** — เป็น inventory ของแบรนด์ถัดไป
3. **ห้ามแตะไฟล์นอกลิสต์ที่ตัวเองเป็นเจ้าของ** (ดู "do NOT touch" ในบรีฟของแต่ละตัว)
4. **ห้ามเหลือคอมเมนต์ HTML `<!-- -->`** ในไฟล์ที่ render จริง — Astro ส่งขึ้น production ตรงๆ
5. **ห้ามเขียน `isActive` เอง** ใน navbar — ใช้ `isActivePath` จาก `../lib/nav`
6. **ห้ามใช้ `define:vars`** บนหน้าที่ index ได้ · **ห้าม `href="#"` / `onclick=`**
7. **ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address` / `email` เข้า JSON-LD**
   — เรียก `pageGraph()` เท่านั้น **ห้ามเขียน JSON-LD ด้วยมือ ห้ามพิมพ์โดเมน
   ห้ามต่อ URL ด้วย `+`**
8. **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`**
9. **`alt` ต้องบรรยายรูปจริง** ห้ามเป็น `"bank"` / `"ภาพที่ 3"`
10. **ย่อหน้าเนื้อความ: `text-left text-base leading-relaxed`** เสมอ ·
    **ห้ามใส่ `mx-auto` / `max-w-*` ให้ `<p>` ในหน้า** (การ์ดคุมความกว้างเองแล้ว)
11. **`description` ที่เขียนเอง = 150-160 ตัวอักษร** (นับ **ตัวอักษร** ไม่ใช่ไบต์) ·
    ที่คัดจากบรีฟ = ใช้ตามความยาวเดิม ห้ามเติม
12. **`terms.astro` / `privacy.astro` ต้อง render ผ่าน `ContentBox.astro` ตัวฐานเสมอ**
    และ **ห้ามมีคลาสสีอยู่ข้างในสองไฟล์นั้น** (สืบทอดจาก `ContentBox` อย่างเดียว)
