  TLD คือ **`.page`** ไม่ใช่ `.com` — operator ระบุมาตรงๆ ในคำสั่ง
- `BRAND_ADDRESS.email` จะกลายเป็น `<mailbox>@ufalion168.page` โดยอัตโนมัติ **ห้ามเขียนมือ**
- `iconVersion` รอบนี้ = `ufalion168` (ASCII ล้วน ไม่ตก fallback แฮช) — **ต่างจากสิบรอบก่อน
  ที่ได้ `168` เท่ากันหมด** รอบนี้ `?v=` จึงเปลี่ยนจริงเป็นครั้งแรกในรอบนาน
- ฟอนต์หมุนกลับไป `kanit` (รอบก่อน `google-sans`) — **แก้บรรทัดเดียวใน brandProfile.ts
  เท่านั้น** ห้ามแตะ `font-family` ที่อื่น ห้ามเติม `<link>` Google Fonts

## §8 กฎที่ build บังคับ (verify-build.mjs จะแดงถ้าผิด)

- โดเมนนอก `ufalion168.page` ใน component ที่ render · `href` ชี้ route ที่ไม่มีจริง ·
  `<h1>` ตัวที่สองในหน้าที่ index ได้ · `alt` หาย · JSON-LD parse ไม่ผ่าน ·
  canonical ผิด host · meta description เกิน 200 ตัวอักษร · `wrangler.toml` name/domain ไม่ตรง
- AVIF ที่ใหญ่กว่า WebP พี่น้องของตัวเอง → ถ้าโดน ให้ **ลด** `quality` ไม่ใช่เพิ่ม
- emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`
- ห้าม `href="#"` ห้าม `onclick=` ห้าม `define:vars` บนหน้าที่ index ได้
- `<address>` ทุกตัวที่ render ต้องมี `BRAND_NAME` ปัจจุบัน และอีเมลต้องอยู่ที่ host ของ `site:`
- `color:` จาก `BRAND_TEXT` บน `<html>` ใน `MainLayout` **ห้ามลบ**
- ห้ามเขียน JSON-LD มือ ใช้ `pageGraph()` · ห้ามเติม `Review` `AggregateRating` `sameAs` `address`
- ห้ามทิ้ง HTML comment `<!-- -->` ในไฟล์ที่ render (Astro ส่งออกตรงๆ)
- description ที่เขียนเอง: **150–160 ตัวอักษร** (นับอักขระ ไม่ใช่ไบต์) — ยกเว้นหน้าแรกที่ใช้ของบรีฟตรงๆ
- `/contact-us` `/ทางเข้า` `/promotion` ต้องได้ `h2 ×0` (หน้าปุ่ม/หน้ารูป ไม่ใช่บทความ)
