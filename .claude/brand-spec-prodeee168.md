## §5 — กฎที่ต้องถือทุกไฟล์ (สรุปจาก playbook — ไม่ใช่ทางเลือก)

1. **ห้ามรัน `npm run build`** — build เดียวของรอบนี้เป็นของ orchestrator ใน Phase 5
2. **ห้ามลบ component variant ที่ไม่ได้ใช้** — เป็น inventory ของแบรนด์ถัดไป
3. **ห้ามเหลือ HTML comment `<!-- -->`** ในไฟล์ที่ render (Astro ส่งลง output ตรงๆ)
   ย้ายโน้ตไปไว้ใน frontmatter แทน
4. **โครมห้าม emit heading tag** ทุกระดับ (ดู §4)
5. **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`** และเป็น **พี่น้อง**
   ของข้อความ ไม่ใช่อยู่ในตัวข้อความ · **ห้ามใส่ emoji นำหน้าข้อความ ticker**
6. **ห้าม `href="#"` ห้าม `onclick=`** · back-to-top ใช้ `<a href="#top">`
7. **`alt` ต้องบรรยายภาพจริง** (ดู §2 ส่วนอาร์ตเวิร์ก) ไม่ใช่ `"bank"` / `"ภาพที่ 3"`
8. **FAQ เป็น `<details>`/`<summary>`** ห้ามกลับไปเป็น button + max-height
9. **ห้าม `define:vars`** · ห้าม render feed เปล่าแล้วเติมด้วย JS ·
   ห้าม `setInterval` ที่ไม่มี guard · ห้ามเอา Swiper กลับมา
10. **navbar ห้ามเขียน `isActive` เอง** — `import { isActivePath } from "../lib/nav"`
11. **ย่อหน้าเนื้อความ: `text-left text-base leading-relaxed <สี>`** ห้าม `text-sm`/`text-lg`
    · หัวข้อจัดกลางได้แต่ `text-center` ต้องอยู่บนตัวหัวข้อเอง ห้ามอยู่บนการ์ด/`<section>`
    · **ห้ามใส่ `mx-auto max-w-4xl` ให้ย่อหน้าในหน้า** (การ์ดคุมความกว้างอยู่แล้ว)
12. **ห้าม re-add wrapper `<div>` รอบ slot** — ทุก `ContentBox*` flatten แล้ว
    (`isolate` บนการ์ด + `-z-10` บนชั้นตกแต่ง) · ถ้าจะเปลี่ยนสีตัวอักษรของการ์ดให้
    **แทนที่** คลาสสีเดิม ห้ามใส่คลาสสีที่สองข้างๆ
13. **JSON-LD มาจาก `pageGraph()` เท่านั้น** ห้ามเขียนมือ ห้ามพิมพ์โดเมน ห้ามต่อ URL
    ด้วย `+` · **ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address` /
    `PostalAddress` / `email`**
14. **`description` ที่เขียนเอง = 150–160 ตัวอักษร** (นับ "ตัวอักษร" ไม่ใช่ไบต์)
    · `Description` ที่บรีฟให้มาใช้ยาวเท่าไหร่ก็ตามนั้น ห้ามเติมให้ครบ 150
15. **ห้ามใส่ `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`**
16. **ห้ามแตะ `src/lib/`** (nav.ts · liveCounter.ts · winnersFeed.ts · schema.ts ·
    thaiProvinces.ts) และ **ห้ามแตะ `src/styles/_sources.generated.css`**
17. **`<Image>`/`<Picture>` ต้องบอก `widths` + `sizes` ตามความกว้างที่วาดจริง**
    · `loading="eager" fetchpriority="high"` ให้เฉพาะ LCP (hero) เท่านั้น
18. **ห้ามแตะ `targetUrl`** ใน login/register — เป็นลิงก์ affiliate ของแบรนด์นี้
