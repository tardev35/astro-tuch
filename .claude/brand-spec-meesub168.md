## §2 พาเลต — ⚠️ รอบนี้เป็น **ธีมสว่าง** แบรนด์แรกของรีโปนี้

อ่านจากอาร์ตเวิร์กจริงของดรอป 2026-10-21 (เปิดดูทุกไฟล์แล้ว):

**โลโก้** = **หัวหมูการ์ตูนสีชมพูอ่อน สวมหน้ากากโจรสีดำ ยิ้มแลบลิ้น** ถัดมาเป็นคำว่า
**"มีทรัพย์" ตัวอักษรไทยสามมิติไล่เฉดชมพูเข้ม→ชมพูอ่อน ขอบขาว** ต่อด้วย
**เลข "168" สามมิติผิวเงิน-ขาวมันวาว** บนพื้นโปร่งใส

**แบนเนอร์** = ฉาก **ฟาร์ม/ทุ่งหญ้ากลางแจ้งแดดจัด** — ท้องฟ้าฟ้าสดมีเมฆขาว หญ้าเขียว
**ยุ้งฉางไม้สีแดง** **กังหันลมไม้** **ฟ่อนฟางสีเหลือง** **รั้วไม้** และ
**หมูการ์ตูนสวมหน้ากากโจรสีดำหลายตัว** ฝั่งซ้ายเป็น **ชายหนุ่มผมสั้นสีเงิน-ขาว
สวมเสื้อกล้ามสีขาวและกางเกงขาสั้นขาว** นั่งพิงฟ่อนฟาง ฝั่งขวาเป็น
**หญิงสาวผมสั้นสีเงิน-ขาว สวมสปอร์ตบราสีชมพูและกางเกงขาสั้นสีชมพู** นั่งบนฟ่อนฟาง
กลางภาพเป็นชื่อแบรนด์ตัวโต ใต้ลงมาเป็น **แคปซูลสีดำขอบชมพูเขียนว่า ระบบดูแลการเงิน**
และ **แถบขาวเขียนว่า ฝากถอนทุกช่องทาง ปลอดภัยไม่ผ่านม้า พร้อมโล่ติ๊กถูกสีชมพู**

**สไลด์ทั้งสอง** = ฉาก **พื้นขาวสว่าง** คู่ชาย-หญิงคนเดียวกับแบนเนอร์ (ชุดขาว / ชุดชมพู)
มี **หมูสวมหน้ากากโจรตรงกลาง** **กล่องของขวัญขาว-ชมพูผูกโบว์** **เหรียญ/ชิปสีชมพูปลิว**
และ **ลูกฟุตบอลขาว-ชมพู** กลางภาพเป็นคำว่า **"โปรโมชั่น"** ตัวอักษรไทยสามมิติสีชมพู

### ⚠️ พื้นเพจ: `src/assets/bg.json` = `{"mode":"color","color":"#f0ccf5"}`

**= ชมพูอมม่วงสว่าง ไม่ใช่สีดำ** นี่คือความต่างที่ใหญ่ที่สุดของรอบนี้ — ทุกแบรนด์

ห้ามสืบทอด ห้าม "แก้" ให้กลับไปเป็นดำ**

## §8 กฎที่ build บังคับ (ย่อ — รายละเอียดอยู่ใน SKILL.md)

- หัวข้อ `<h1>/<h2>/<h3>` ต้องมาจากบทความเท่านั้น **โครมห้ามถือ heading tag ทุกระดับ**
  (ticker, winners feed, review cards, footer columns, badge, card labels → `<p>`/`<span>`
  + `aria-label` บน `<section>`) — **หนึ่ง `<h1>` ต่อหน้าเท่านั้น**
- ห้ามมี HTML comment `<!-- … -->` ในไฟล์ที่ render (Astro ส่งขึ้น production ตรงๆ)
  → ตอน retheme ไฟล์ไหน ให้ลบคอมเมนต์ HTML ในไฟล์นั้นไปด้วย ย้ายคำอธิบายไป frontmatter
- อิโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และ **ห้ามฝังในข้อความ prop**
- ห้าม `href="#"` ห้าม `onclick=` ห้าม `define:vars` ห้ามเขียน `isActive` เอง
  (ใช้ `isActivePath` จาก `../lib/nav`)
- `alt` ต้องบรรยายรูปจริง ห้ามเป็น `"bank"` / `"ภาพที่ 3"`
- FAQ ต้องเป็น `<details>`/`<summary>` ห้ามกลับไปเป็นปุ่ม + `max-height`
- JSON-LD มาจาก `pageGraph()` เท่านั้น ห้ามเขียนมือ ห้ามใส่ `Review` `AggregateRating`
  `sameAs` `address`/`PostalAddress` `email`
- ที่อยู่/อีเมลมาจาก `BRAND_ADDRESS` เท่านั้น — ตั้ง `BRAND_NAME` แล้วเสร็จ ห้ามพิมพ์เอง
  footer ที่ใช้งานอยู่ **ต้อง** render บล็อก `<address>` (คัดจาก SKILL.md แบบ verbatim
  **ห้าม theme ห้ามใส่ hex**)
- `<html>` ต้องคง inline `color:` ที่มาจาก `BRAND_TEXT` ไว้
- ห้ามแตะ `src/styles/_sources.generated.css` (build เขียนเอง)
- ห้ามเติม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`
- ห้ามแตะโครงสร้าง `<head>` ของ `MainLayout` (ลำดับบล็อกมาจาก `brandProfile`)
  และห้ามทิ้ง `?v=${iconVersion}` ออกจากลิงก์ไอคอน
- ย่อหน้าในการ์ด: `text-left text-base leading-relaxed` เสมอ ห้าม `mx-auto`/`max-w-*`
  บน `<p>` ในหน้า และหัวข้อจัดกลางได้แต่ต้องใส่ `text-center` ที่หัวข้อเอง ไม่ใช่ที่การ์ด
- **ห้าม `npm run build`** — orchestrator build ครั้งเดียวใน Phase 5
