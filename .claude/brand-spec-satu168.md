## §2 พาเลต — เขียวมรกตนำ · ทองสัมฤทธิ์รอง · **ธีมสว่าง**

อ่านจากอาร์ตเวิร์กจริงของดรอป 2026-10-21 (เปิดดูทุกไฟล์แล้ว):

**โลโก้** (`logo.webp`, พื้นโปร่งใส) = คำว่า **"สาธุ" ตัวอักษรไทยสามมิติผิวมันวาว
ไล่เฉดเขียวมรกตเข้ม→เขียวใบตองสว่าง ขอบขาว** ต่อด้วย **เลข "168" สามมิติผิวทองเหลือง
มันวาวไล่เฉดทองเข้ม→ทองอ่อน**

**แบนเนอร์** (`banner1.png`, 2243x701 แนวนอน) = ฉาก **วัดไทย/พระบรมมหาราชวังกลางแจ้ง
แดดจัด** — เจดีย์และยอดปราสาททองหลายองค์ ท้องฟ้าฟ้าอ่อนมีเมฆขาว ใบบัวและดอกบัวชมพู
ด้านหน้า **ฝั่งซ้าย** เป็น **ชายหนุ่มผมสั้นสีดำ สวมชุดไทยโจงกระเบนสีครีม-ทองลายปัก
สวมสร้อยและกำไลทอง มือถือสลากกินแบ่งรัฐบาล** **ฝั่งขวา** เป็น **หญิงสาวผมสั้นสีดำ
ทัดดอกไม้ขาว สวมชุดไทยสไบลายทอง สร้อยและต่างหูทอง มือถือสลากกินแบ่งคลี่เป็นพัด**
**กลางภาพ** เป็นชื่อแบรนด์ตัวโต **"สาธุ" เขียวมรกตสามมิติ ต่อด้วย "168" ทองสามมิติ**
ใต้ลงมาเป็น **แคปซูลพื้นดำขอบทองเขียนว่า "เว็บหวย" (ขาว) + "จ่ายจริงไม่โกง" (ทอง)**
และ **แถบทองขอบมนเขียนว่า "ระบบแทงหวย รัฐบาลไทย ฮานอย ลาว หุ้น"** มีไอคอนเหรียญทอง
และไอคอนกราฟแท่งขึ้นขนาบสองข้าง มุมล่างมี **ลูกบอลหวยขาว-ดำเลข 6 / 9**

**สไลด์ทั้งสอง** (`slide1.png` / `slide2.png`, 540x600 **แนวตั้ง**) = ฉากวัดไทย
เจดีย์ทองเหมือนแบนเนอร์ คู่ชาย-หญิงชุดไทยคู่เดิมถือสลาก มีดอกบัว ใบบัว เหรียญทอง
และลูกบอลหวยกระจายด้านล่าง กลางภาพเป็นคำว่า **"โปรโมชั่น"** ตัวอักษรไทยสามมิติทอง
ใต้ลงมาเป็นแผ่นป้ายพื้นดำขอบทอง:
- **`slide1.png` → ป้ายอ่านว่า "แนะนำเพื่อน" + "0.8%"**
- **`slide2.png` → ป้ายอ่านว่า "คืนยอดเสีย" + "0.3%"**

⚠️ **การจับคู่นี้อ่านจากตัวหนังสือบนรูปจริงรอบนี้ ห้ามสืบทอดจากรอบก่อน** — uploader
เขียนทับทั้งสองไฟล์ทุกดรอป เลขไฟล์ไม่มีความหมายข้ามแบรนด์

### ⚠️ พื้นเพจ: `src/assets/bg.json` = `{"mode":"color","color":"#d8ffc7"}`

**= เขียวมิ้นต์สว่าง** `bg.json` คือแหล่งเดียวของค่านี้ **ห้ามสืบทอด ห้าม "แก้" ให้
กลับไปเป็นดำ** รอบนี้จึงเป็น **ธีมสว่างรอบที่สอง**ของรีโปนี้ (รอบก่อน มีทรัพย์168
เป็น `#f0ccf5` ชมพูอมม่วง) — **ตัวที่เปลี่ยนคือฮิวทั้งชุด + variant ทั้งเจ็ดตระกูล
ไม่ใช่ทิศของธีม**

## §8 กฎที่ build บังคับ (ย่อ — รายละเอียดอยู่ใน SKILL.md)

- **`<h1>` ได้หน้าละหนึ่งตัว** และ **โครมห้ามถือ heading ทุกระดับ** — label ของ
  ticker / winners feed / review card / การ์ด / คอลัมน์ ต้องเป็น `<p>`/`<span>`
  ที่ถือคลาสเดิม และย้ายหน้าที่ตั้งชื่อ region ไปที่ `aria-label` บน `<section>`
- **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`** และเป็น **พี่น้อง**
  ของ label ไม่ใช่อยู่ในข้อความ · **ห้ามใส่ emoji นำหน้าใน text prop**
- **ห้าม `href="#"` และห้าม `onclick=`** · ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
- **`alt` ต้องบรรยายรูปจริง** (ของโปสเตอร์โปรโมชั่น = ข้อความที่พิมพ์อยู่บนรูป)
  รูปซ้ำเพื่อความต่อเนื่องใช้ `alt=""` + `aria-hidden="true"` ที่ wrapper
- **FAQ เป็น `<details>`/`<summary>`** ห้ามกลับไปใช้ button + max-height
- **ห้าม `define:vars`** และห้าม `<script>` ที่ไม่มี attribute บนหน้าที่ index
- **ห้าม `Math.random()` / `Date` ใน frontmatter** — ใช้ `brandPick`/`brandFlag`
- **`isActivePath` จาก `../lib/nav` เท่านั้น** ห้ามเขียน `isActive` เอง
- **JSON-LD มาจาก `pageGraph()` เท่านั้น** ห้ามพิมพ์โดเมน ห้ามต่อ URL ด้วย `+`
  ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address` / `email`
- **ห้ามลบ `color:` ใน style ของ `<html>`** ใน `MainLayout` (มาจาก `BRAND_TEXT`)
- **ห้ามเพิ่ม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`**
- **ห้ามแก้ `src/styles/_sources.generated.css`** (build เขียนเอง)
- **AVIF ต้องเล็กกว่า WebP ของตัวเอง** — แก้ด้วยการ **ลด** `quality` เท่านั้น
- **ห้ามรัน `npm run build`** — orchestrator build ครั้งเดียวใน Phase 5
