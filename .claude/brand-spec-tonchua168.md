## §2 พาเลตต์ — **ชมพูบับเบิลกัมนำ · ทองเนยเป็นฮิวที่สอง · พลัมเข้มไม่เคยถือตัวอักษร · บนดำสนิท**

อ่านจากอาร์ตเวิร์กจริง (เปิดดูด้วย Read ทั้ง `logo.webp` `banner1.png` `banner1-mobile.png` `slide1.png` `slide2.png`):
โลโก้เป็น **แมวการ์ตูนสีขาว-ชมพู** หน้ายิ้มหลับตา นั่งคู่กับมือถือจอชมพูที่มีลูกศรดาวน์โหลด
และปึกแบงก์ชมพู อยู่เหนือคำว่า **ถอน** (ตัวอักษรไทยหนาสามมิติ **สีทองเนย** ตัดขอบชมพู) ต่อด้วย
**ชัวร์168** (ตัวอักษร+ตัวเลขสามมิติ **สีชมพูบับเบิลกัม** ตัดขอบทอง) ล้อมด้วย **หัวใจชมพู** และ
**ประกายดาวทอง** พื้นหลังโลโก้โปร่ง
แบนเนอร์เป็นฉากพื้นดำ มี **หญิงสาวผมเงิน** ประดับดอกซากุระชมพูกับปิ่นทองอยู่ฝั่งขวา สวมชุดชมพูปักทอง
ถือเหรียญบิตคอยน์ทอง ข้างๆ มี **มือถือจอชมพูขึ้นเครื่องหมายถูกในวงกลมชมพู พร้อมคำว่า ถอนสำเร็จ**
พื้นล่างเป็น **ปึกแบงก์ชมพู** กับ **กองเหรียญทอง** และ **ริบบิ้นซาตินชมพู** พลิ้วทั่วภาพ
พื้นเพจ = `bg.json` ของดรอปนี้ = `{"mode":"color","color":"#000000"}` → **ดำสนิท**

## §3 variant ที่เลือกรอบนี้ — ห้าม subagent เปลี่ยน

ทุกตระกูลหมุนออกจากตัวที่รอบก่อนใช้ (อ่านจาก `git show HEAD:src/layouts/MainLayout.astro` และ
`git show HEAD:src/pages/index.astro`) **ไม่มีตระกูลไหนใช้ตัวเดิมซ้ำเลย**

| ตระกูล | รอบก่อน (มีโชค168) | **รอบนี้ (ถอนชัวร์168)** |
|---|---|---|
| Navbar | `NavbarStyle8` | **`NavbarStyle5`** |
| Footer | `FooterStyle3` | **`FooterCyber`** |
| Announcement | `Announcement3` | **`Announcement6`** |
| LatestWinners | `LatestWinners3` | **`LatestWinners`** (ตัวฐาน) |
| Faq | `Faq4` | **`Faq`** (ตัวฐาน) |
| ReviewCard | `ReviewCardSumo` | **`ReviewCardSumo2`** |
| ContentBox mix | FloatingBadge · TwoCyberCut · ContentBox · SevenThreePremium · SevenThree · 3ThreeCyberCut · Neumorphism | **Premium · CyberCut · Special · SevenThreeNeumorphism · SevenThreeCyberCut · 3ThreePremium · TwoPremium** |
| BRAND_FONT | `google-sans` | **`kanit`** |

`ContentBox.astro` (ตัวธรรมดา) **ไม่อยู่ในมิกซ์ของ index รอบนี้** แต่ยังเป็น "ตัวที่ live ตลอด"
เพราะ terms / privacy / 404 / promotion / หน้าปุ่ม ทุกหน้า render ผ่านมัน → อยู่ในชุด chrome ที่
orchestrator retheme ให้แล้วใน P1

`ContentBoxTwo.astro` live เหมือนกัน แต่เข้าถึงผ่าน `LoginRtpSection` เท่านั้น ไม่ได้ถูก import
จาก `index.astro` ตรงๆ — เช็ก "ใช้อยู่ไหม" ต้อง grep ด้วยชื่อไฟล์เปล่า

**ห้ามลบ variant ที่ไม่ได้ใช้** ทุกตัวคือ inventory ของแบรนด์ถัดไป สีแบรนด์เก่าที่ค้างอยู่ข้างใน
ไฟล์ที่ไม่ได้ render = drift ที่คาดไว้แล้ว ไม่ใช่บั๊ก

## §7 กฎที่ห้ามพลาด (ย่อจาก SKILL.md — รายละเอียดเต็มอยู่ที่นั่น)

1. **ห้าม `npm run build`** — orchestrator build ครั้งเดียวใน P3
2. **ห้ามลบ component ที่ไม่ได้ใช้** — เป็น inventory
3. **chrome ห้ามถือ heading tag ทุกระดับ** ป้าย widget/การ์ด/ticker เป็น `<p>`/`<span>` +
   `aria-label` บน `<section>`
4. **ห้ามมี HTML comment `<!-- -->`** ในไฟล์ที่ render — Astro ส่งออกไป dist จริง
5. **ห้าม `define:vars`, ห้าม `href="#"`, ห้าม `onclick=`** · emoji ตกแต่งต้องอยู่ใน element ที่มี
   `aria-hidden="true"` · `alt` ต้องบรรยายรูปจริง
6. **JSON-LD มาจาก `pageGraph()` เท่านั้น** ห้ามเขียนมือ ห้ามใส่ `Review`/`AggregateRating`/
   `sameAs`/`address`/`email`
7. **ย่อหน้าในการ์ดชิดซ้าย `text-left text-base leading-relaxed`** ห้าม `mx-auto max-w-*`
   คร่อมย่อหน้าในหน้าเพจ
8. **`<strong>` ใช้สีเดียวคือ `#ffd84d`** และต้องคลุมคำเป็นก้อนเต็ม (ภาษาไทยไม่มีช่องว่างระหว่างคำ)
   ห้ามวาง `<strong>` สองอันติดกัน
9. `/contact-us` `/ทางเข้า` `/login` `/register` = **หน้าปุ่ม** และ `/promotion` = **หน้ารูป**
   ทั้งห้าหน้า **`h2×0`** — มีแค่ `<h1>` เดียวจาก `ContentBox as="h1"` · `/promotion` มีย่อหน้าเกริ่น
   ได้ **หนึ่งย่อหน้า ~4 บรรทัด** เท่านั้น
10. **ห้ามแตะ `targetUrl`** ใน `login.astro`/`register.astro` (ลิงก์ affiliate ของแบรนด์นี้)
11. `terms.astro` `privacy.astro` brand-neutral โดยโครงสร้าง — **ห้ามใส่คลาสสีลงในกล่อง** และต้อง
    render ผ่าน `ContentBox.astro` ตัวธรรมดาเสมอ
12. **ห้าม deploy ห้าม `git push` ห้าม `git commit`** รอบนี้ — หยุดที่ build + verify
