## §2 พาเลต — **ล็อกค่าแล้ว ห้ามเดาเพิ่ม ห้ามดูดสีจากรูปเอง**

### 🚨🚨 รอบนี้ "สว่างทั้งเว็บ" — กลับทิศ 180° จากรอบก่อน

`src/assets/bg.json` ของดรอปนี้คือ `{"mode":"color","color":"#e1fef3"}` =
**เขียวมินต์จางเกือบขาว** และ `bg.json` คือ **แหล่งเดียว** ของพื้นเพจ
รอบก่อน (WIN8S) เป็น `#1e0101` ดำอมเลือดหมู = มืดทั้งเว็บ **รอบนี้ตรงข้ามสุดขั้ว**

→ **การ์ดเนื้อหาเป็นผิวสว่าง หมึกเข้ม** ห้ามคงการ์ดเข้มของรอบก่อนไว้แม้แต่ใบเดียว
→ `BRAND_TEXT` รอบนี้เป็น **หมึกเข้ม** (`#0d3326`) ไม่ใช่หมึกสว่าง ถ้าเผลอคง
   การ์ดเข้มไว้ ตัวอักษรบนการ์ดนั้นจะ **หายไปเลย** ไม่ใช่แค่จางลง
→ **โครม (navbar/footer/ticker) เป็นเขียวเข้ม** เพื่อให้แยกจากพื้นเพจสว่าง —
   นี่คือจุดเดียวของเว็บที่เป็นผิวเข้ม

   จะถือตัวอักษรได้เฉพาะเมื่อนั่งบนโครมเข้ม `#052e22`/`#03201a` เท่านั้น

🚨🚨 **ห้ามดันปลายอ่อนขึ้นไปถึง `#19a97c`** — ขาวบนค่านั้นได้แค่ **3.0:1 ตกเกณฑ์**
(`#19a97c` เป็นเส้น/ออรา/พื้นถมเท่านั้น ตามตารางข้างบน)
🚨 **ห้ามใช้หมึกเข้ม `#0d3326` บนปุ่มนี้** — ตกทุก stop

**ปุ่มทอง** = พื้น `#e2b32a` + หมึก `#0d3326` (8.4:1) — ทองเป็น **พื้น** ไม่ใช่หมึก

**rgba() ที่อนุญาตรอบนี้** — ห้ามมีค่าอื่น:
`rgba(4,108,78,α)` · `rgba(25,169,124,α)` · `rgba(47,212,155,α)` ·
`rgba(226,179,42,α)` · `rgba(13,51,38,α)` · `rgba(5,46,34,α)` · `rgba(3,32,26,α)`

### 🎯 inventory ที่ index ต้องได้: **h1 ×1 · h2 ×5 · h3 ×2**

**จุดที่ชั้น heading รั่วได้ — กันทุกจุด:**
- บรรทัด 15/17/19 (`ขั้นตอนที่ 1/2/3`) **ไม่มี prefix H ในบรีฟ** → ส่งเข้า
  `titleleft`/`titlecenter`/`titleright` ของ `ContentBox3Three` โดย
  **ไม่ส่ง `heading`** (default `false` → render เป็น `<p>`)
- **ไม่ส่ง `titleright`** ให้ `ContentBoxTwoHuay` และ SevenThree ทั้งสองใบ →
  ซีกขวา/คอลัมน์ภาพจึงไม่มี heading
- คำถามใน `Faq3` เป็น `<span>` ใน `<summary>` ไม่ใช่ heading — **ห้ามเลื่อนขึ้น**
- โครมทุกตัว (`AnnouncementHuay` · `LottoGrid` · `LatestWinnersHuay` ·
  `ReviewCardSumo2` · `Navfoot` · navbar · footer) ขึ้นป้ายเป็น `<p>`/`<span>`
  พร้อม `aria-label` บน `<section>` — **ห้ามเลื่อนเป็น h2 เพื่อ "แก้ชื่อที่ขาด"**
- ก่อนจบ: `grep -n '<h[1-6]' ` ทุก component ที่หน้าของคุณเรียก — ทุกแท็ก heading
  ต้อง interpolate มาจาก prop (= มาจากบรีฟ) **ห้ามมีสตริงไทย hardcode เป็น heading**

## §7 หน้าเว็บรอบนี้ — เปิด/ปิด

**แบรนด์นี้เป็นเว็บหวย** → `/ตรวจหวย` และ `/แนวทาง` **ต้องเปิด**
(orchestrator ย้ายไฟล์จาก `src/pages-disabled/` → `src/pages/` ให้แล้วใน P1
และใส่ลิงก์ใน `NavbarHuay` + ยืนยันลิงก์ใน `FooterHuay` แล้ว)

**cta toggle = เปิด** → `login.astro` / `register.astro` เป็น **หน้าปุ่ม** (มี
`const targetUrl` + render `CtaRedirect`) → `ทางเข้า` **ไม่มีในเมนู** โดยตั้งใจ
แต่ยังเป็น route ที่ index ได้ **ห้ามลบไฟล์ และห้ามเติมลิงก์กลับเข้าเมนู**

ลำดับเมนูที่ orchestrator ตั้งไว้ใน `NavbarHuay`:
`หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · ตรวจหวย · แนวทาง · ทดลองเล่น · เกี่ยวกับเรา · ติดต่อเรา`

**หน้าที่ไม่มีบทความ — ห้ามเขียน `<h2>` หรือย่อหน้าอธิบายลงไปเด็ดขาด:**
- `/contact-us` → h1 ×1 · **h2 ×0** · โครงสร้าง: title → ภาพ LINE → `BRAND_ADDRESS` → แถวปุ่ม
- `/ทางเข้า` → h1 ×1 · **h2 ×0** · โครงสร้าง: title → กริดปุ่ม 2 คอลัมน์
- `/promotion` → h1 ×1 · **h2 ×0** · title → **intro ย่อหน้าเดียว ~4 บรรทัด (งบคำทั้งหน้า)** → กริดภาพ slide → ปุ่มสมัคร
- `/login` · `/register` → h1 ×1 · **h2 ×0** · title → ปุ่มเดียวไป `targetUrl`
  **ห้ามแก้ `targetUrl`** (เป็นลิงก์พันธมิตรของแบรนด์นี้) และคง `rel="nofollow sponsored"`

ถ้าหน้าที่คุณรับมามี `<h2>` + ย่อหน้าอยู่แล้ว → **ลบทิ้ง** นั่นคือการแก้บั๊ก ไม่ใช่เกินสโคป
(บรีฟไม่มีส่วน SUB-PAGES เลย ย่อหน้าพวกนั้นคือของที่รอบก่อนๆ แต่งขึ้นเอง)

**หน้าที่เป็นบทความจริง** (หัวข้อมาจากตัวบทความของหน้าเอง ไม่ใช่ checklist §4):
`/about-us` · `/ทดลองเล่น` · `/ตรวจหวย` · `/แนวทาง` · `/terms` · `/privacy`

`terms` / `privacy` **brand-neutral โดยโครงสร้าง** — ทุกคำที่เป็นชื่อแบรนด์มาจาก
`BRAND_NAME` และ render ผ่าน **`ContentBox.astro` เท่านั้น** (ไม่ใช่ variant ที่ index
เลือกรอบนี้) 🚨 **ห้ามใส่คลาสสีลงใน `<p>` ของสองหน้านี้** — ย่อหน้า inherit สีจากการ์ด
`privacy` บรรยายสิ่งที่เว็บทำจริง: static build · ไม่มี analytics · ไม่มี pixel ·
ไม่มี cookie banner · ไม่มีฟอร์มที่ post ไปไหน — **อย่าแก้ให้ขัดกับความจริง**

## §8 กฎที่ build บังคับ (`tools/verify-build.mjs` — exit non-zero = build แดง)

- emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และ **ห้ามอยู่ใน
  text prop** (เช่นข้อความ ticker — marquee อ่านซ้ำสามรอบ)
- ไอคอนเมนู/ไอคอนตกแต่ง = `<span aria-hidden="true">` ที่เป็น **พี่น้อง** ของ label
  ห้ามอยู่ **ใน** ข้อความ label
- **ห้าม `href="#"` · ห้าม `onclick=`** — back-to-top ใช้ `<a href="#top">`
- `alt` ต้องบรรยายภาพ (ห้าม `"bank"` / `"ภาพที่ 3"`) · ภาพตกแต่งซ้ำใช้ `alt=""`
  **พร้อม** `aria-hidden="true"` บน wrapper
- FAQ = `<details>`/`<summary>` **ห้ามมี `<script>` ห้ามกลับไปเป็น button+max-height**
- **ห้าม `define:vars`** และห้ามมี `<script>` ที่ไม่มี attribute บนหน้าที่ index ได้
- วิดเจ็ตที่ป้ายเป็น `<p>` ต้องมี `aria-label` บน `<section>` — **ห้ามเลื่อนเป็น h2**
- `<h1>` ได้หน้าละ **หนึ่งใบเท่านั้น**
- AVIF ห้ามใหญ่กว่า WebP คู่ของตัวเอง (image service rescale ให้แล้ว — อย่าแตะ)
- JSON-LD ต้อง parse ได้ · canonical ต้องตรง host · description ≤ 200 ตัวอักษร
- ไอคอนใน `public/` ที่ไม่มีใครลิงก์ = build แดง
- **`<address>` ทุกใบที่ render ต้องมี `BRAND_NAME` ปัจจุบัน** และอีเมลต้องอยู่บน
  host ของ `site:` (มาจาก `BRAND_ADDRESS` อัตโนมัติ — **ห้ามพิมพ์เอง**)
- `color:` ใน style attribute ของ `<html>` (= `BRAND_TEXT`) **ห้ามหาย**

**structured data:** เรียก `pageGraph()` จาก `src/lib/schema.ts` เท่านั้น
ห้ามเขียน JSON-LD มือ · ห้ามพิมพ์โดเมน · ห้ามต่อ URL ด้วย `+` ·
**ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address` / `PostalAddress` / `email`**

**behaviour อยู่ใน `src/lib/`** — `isActivePath` จาก `../lib/nav` (ห้ามเขียน
`isActive` มือ) · `winnersFeed.ts` · `liveCounter.ts` **ห้ามย้าย logic กลับเข้า
component `<script>`** · ห้ามเอา Swiper กลับมา

**ห้ามมี HTML comment `<!-- -->`** ใน component/หน้าที่ render จริง
(Astro ship ลง dist ตรงๆ) — คอมเมนต์ JS ใน frontmatter ปลอดภัย ใช้ตัวนั้นแทน
**ห้ามใส่ `{/* */}` ข้างแท็กที่เป็นกิ่งของ ternary** (build พัง)

**ห้ามเพิ่ม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`**
(ทำให้ Astro แปะ `data-astro-cid-*` ลงทุก element)

**ห้ามแก้ `src/styles/_sources.generated.css`** (build เขียนเอง)
**ห้ามสร้าง `public/robots.txt`** (มี route generate ให้แล้ว)

## §9 house style ของเนื้อความ

- element ที่ถือ `<slot />` ได้ **`text-left text-base leading-relaxed` + สีหมึก
  `#0d3326`** — ห้าม `text-sm` ห้าม `text-lg` กับเนื้อความ
- หัวข้อจัดกึ่งกลางได้ แต่ `text-center` ต้องอยู่บน **ตัวหัวข้อเอง** ห้ามอยู่บน
  การ์ด/`<section>` (จะ inherit ลง slot แล้วย่อหน้ากลางตาม)
- **ห้ามใส่ `mx-auto max-w-*` บน `<p>` ในหน้า** — การ์ดคุมความกว้างเองแล้ว
- single-slot variant **flatten แล้วทั้งหมด** (`isolate` บนการ์ด + `-z-10` บนชั้น
  ตกแต่ง) **ห้ามเพิ่ม wrapper `<div>` รอบ slot กลับมา**
- เปลี่ยนสีตัวอักษรของการ์ด = **แทนที่** คลาสสีเดิม ไม่ใช่ใส่คลาสที่สองข้างๆ
- consumer ส่ง **หนึ่ง element ต่อหนึ่ง slot** เท่านั้น
