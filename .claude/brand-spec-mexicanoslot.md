## §5 คลังคำของบรีฟรอบนี้ (ใช้ได้) vs คำต้องห้าม

### ✅ คำของบรีฟรอบนี้ (ใช้ซ้ำได้ทุกหน้า)
สล็อตเมกซิกัน · เดิมพันออนไลน์ · สดส่งตรงจากเมกซิกัน · เว็บแท้ที่นี่ที่เดียว ·
การันตีเว็บตรง · ยอดเข้าบริษัท · ไม่ผ่านเอเย่นต์ · สล็อตคลาสสิก · เกมโบนัส ·
เกมที่มีฟีเจอร์พิเศษ · โปรโมชั่นอัปเดตใหม่ตลอดสัปดาห์ · คืนยอดเสีย 0.3% ·
แนะนำเพื่อน โบนัส 0.8% · สมัครด้วยตัวเอง 3 ขั้นตอน · แอดมินออนไลน์ตลอด 24ชม. ·
กติกาเกม · อัตราการจ่ายรางวัล · ข้อกำหนดการใช้งาน

### 🚨 บรีฟรอบนี้ "โฆษณาและกำกับในประโยคเดียวกัน" — **ship ทั้งสองครึ่ง**
หัวข้อของบรีฟเองโฆษณาว่า *การันตีเว็บตรง / ยอดเข้าบริษัทแน่นอน / ไม่ผ่านเอเย่นต์ /
สดส่งตรงจากเมกซิกัน* ขณะที่ย่อหน้าของบรีฟเองกำกับกลับว่า:
- *ข้อมูลเกี่ยวกับการส่งตรงจากเม็กซิโกควรตรวจสอบแหล่งที่มาของเกมและผู้ให้บริการก่อนใช้งาน*
- *คำกล่าวอ้างว่าไม่ผ่านเอเย่นต์หรือยอดเงินเข้าบริษัทโดยตรง จำเป็นต้องมีข้อมูลที่ตรวจสอบได้ประกอบ*
- *เครดิตคืนยอดเสียไม่ได้หมายความว่าจะได้รับเงินคืนจากทุกการเดิมพันหรือเพิ่มโอกาสชนะในครั้งต่อไป*
- *แม้จะมีข้อความว่าไม่จำกัด แต่ควรยืนยันจำนวนบัญชีที่เข้าร่วมได้ รอบจ่ายเครดิต*
- *ควรตรวจสอบเวลาการให้บริการจริงจากประกาศล่าสุดอีกครั้ง*

**ห้ามตัดครึ่งกำกับทิ้งเพราะฟังดูลบ และห้ามขยายครึ่งโฆษณาเป็นคำกล่าวอ้างใหม่**

## §8 กฎแข็งที่ทุก agent ต้องถือ

1. **ห้ามลบ component variant ที่ไม่ได้ใช้** — เป็น inventory ของแบรนด์ถัดไป
2. **ห้ามรัน `npm run build`** — orchestrator build ครั้งเดียวใน Phase 5
3. **ห้ามเหลือ HTML comment `<!-- -->`** ในไฟล์ที่ render จริง (Astro ส่งขึ้น production)
   — คอมเมนต์อธิบายให้อยู่ใน frontmatter (`//`) เท่านั้น
4. **chrome ห้ามออกแท็ก heading ทุกระดับ** — ป้ายของ widget/ticker/การ์ด เป็น
   `<p>`/`<span>` + `aria-label` บน `<section>`
5. **ห้ามเขียนโดเมนมือ ห้ามต่อ URL ด้วย `+`** — ทุก URL มาจาก `pageGraph()` / `canonicalFor()`
6. **ห้ามเพิ่ม `Review` / `AggregateRating` / `sameAs` / `address` / `PostalAddress` / `email` ใน JSON-LD**
7. **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และเป็นพี่น้องของข้อความ**
   — ห้ามฝังใน text prop
8. **ห้าม `href="#"` ห้าม `onclick=`** · back-to-top ใช้ `<a href="#top">`
9. **ห้าม `define:vars`** บนหน้า indexable · navbar ต้องใช้ `isActivePath` จาก `../lib/nav`
10. **`alt` ต้องบรรยายภาพจริง** (อ่านจาก §6) ไม่ใช่ `"banner"` / `"ภาพที่ 3"`
11. **ย่อหน้าในเพจห้ามมี `mx-auto` / `max-w-*`** — การ์ดคุมความกว้างเองแล้ว
12. **`description` ที่เขียนเอง = 150-160 ตัวอักษร** (นับ **ตัวอักษร** ไม่ใช่ไบต์)
    — ของหน้าแรกคัด verbatim จากบรีฟ ห้ามต่อเติม
13. **ห้ามเพิ่ม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`**
14. **ห้ามแก้ `src/lib/` ทุกไฟล์** (นอกจาก `brandProfile.ts` ที่ orchestrator ทำใน P1)
