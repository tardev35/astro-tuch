## §7 — กฎที่บังคับด้วย build (verify-build.mjs จะแดงถ้าผิด)

- `<h1>` หนึ่งตัวต่อหน้า · `alt` ต้องบรรยายภาพจริง · emoji ตกแต่งต้องอยู่ใน
  `<span aria-hidden="true">` ที่เป็น **พี่น้อง** ของข้อความ · ห้าม `href="#"` ·
  ห้าม `onclick=` · ห้าม `define:vars` / `<script>` ไร้ attribute บนหน้าที่ index
- JSON-LD มาจาก `pageGraph()` เท่านั้น · ห้ามพิมพ์โดเมน · ห้ามต่อ URL ด้วย `+` ·
  ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address` / `email`
- `<address>` ทุกบล็อกต้องมี `BRAND_NAME` ปัจจุบัน และอีเมลต้องอยู่บน host ของ `site:`
- meta `description` ที่เขียนเอง **150–160 ตัวอักษร** (นับ character ไม่ใช่ byte)
  ⚠️ `description` ของหน้าแรกมาจากบรีฟตรงตัว (~120 ตัวอักษร) **ห้ามเติมให้ครบ 150**
- AVIF ต้องไม่ใหญ่กว่า WebP คู่ของมัน (image service ปรับ quality ให้เองแล้ว)
- ห้ามมีคอมเมนต์ HTML `<!-- -->` ในไฟล์ที่ render (Astro ส่งขึ้น production ตรงๆ)
- `color:` จาก `BRAND_TEXT` บน `<html>` ต้องอยู่ครบ
- `isActivePath` จาก `../lib/nav` เท่านั้น **ห้ามเขียน isActive เอง**
- ย่อหน้าในกล่อง: `text-left text-base leading-relaxed` **ห้าม `mx-auto` / `max-w-*` ใน `<p>` ของหน้า**
