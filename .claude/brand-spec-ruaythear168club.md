### สิ่งที่อยู่ในภาพรอบนี้

- **โลโก้** — พื้นโปร่งใส ซ้ายสุดเป็น **ตะกร้าสานทองคำใส่เหรียญทองล้นตะกร้า**
  (ตะกร้ามีหูจับ เหรียญกลมสีทองมีสัญลักษณ์อยู่บนเหรียญ) ต่อด้วยคำว่า **"ร่ำรวย"**
  ตัวอักษรไทยหนาสามมิติ **ผิวฟ้าไซยานมันวาว ไล่เฉดจากฟ้าอ่อนด้านบนลงฟ้าเข้มด้านล่าง**
  แล้วต่อด้วยเลข **"168"** ตัวหนาสามมิติ **ผิวโครเมียมเงิน** ทั้งหมดตัดขอบดำหนา
  มีแสงสะท้อนขาวและเงาฟ้าเรืองรอบตัวอักษร
  → **สัญลักษณ์ประจำแบรนด์รอบนี้คือ "ตะกร้าเหรียญทอง" ตัวเดียว**
- **banner1 (แนวนอน)** — ฉาก **ห้องนั่งเล่นหรูโทนครีม-งาช้าง** แสงนุ่มจากหน้าต่าง
  ฝั่งซ้ายเป็น **ผู้หญิงสูงวัยผมสั้นดัดลอนสีขาวเงิน สวมแว่นกันแดดทรงนักบินเลนส์ดำ
  ทาลิปสติกแดง ใส่สูทซาตินสีงาช้างทับเสื้อรัดรูปสีขาว สวมสร้อยไข่มุก ต่างหูไข่มุก
  แหวนไข่มุก และนาฬิกาข้อมือทอง มือซ้ายยกแก้วแชมเปญ นั่งเอนอยู่บนโซฟาผ้าสีครีม**
  ฝั่งขวาเป็น **โลโก้ขนาดเล็กด้านบน** ถัดลงมาเป็น **ข้อความสามมิติตัวโต "ร่ำรวย" สีฟ้า
  ไซยาน + "168" ผิวโครเมียมเงิน ต่อท้ายด้วย "เกมสล็อตจ่ายแพง" สีฟ้า** และใต้สุดเป็น
  **แคปซูลมนสีฟ้าน้ำเงินขอบเงิน เขียนว่า "ปรับเรทแตกหนักที่สุดในวงการ"**
- **banner1-mobile (จัตุรัส)** — ผู้หญิงคนเดียวกัน แต่ **มือขวาจับขอบแว่นกันแดด**
  ใส่สูทซาตินงาช้าง เข็มขัดหัวทอง กำไลทอง นาฬิกาทอง สร้อยไข่มุก นั่งบนโซฟาครีม
  ข้อความชุดเดียวกับ banner1 แต่จัดเป็นสามบรรทัดซ้อน
- **slide2 (600x480)** — ผู้หญิงคนเดียวกัน **จับขอบแว่นกันแดด** นั่งบนโซฟาครีม
  โลโก้มุมบน ตรงกลางเป็น **คำว่า "โปรโมชั่น" ตัวอักษรไทยสามมิติตัวโตสีฟ้าไซยาน**
  ใต้ลงมาเป็น **แคปซูลฟ้าน้ำเงินเขียนว่า "คืนยอดเสีย" ต่อท้ายด้วยเลข "0.3%" ตัวโต**
- **slide1 (600x480)** — ผู้หญิงคนเดียวกัน **ชี้นิ้วด้วยมือทั้งสองข้าง ยิ้มกว้าง**
  ใส่สูทซาตินงาช้าง เข็มขัดหัวทอง โลโก้มุมบน ตรงกลางเป็น **คำว่า "โปรโมชั่น"
  ตัวอักษรไทยสามมิติตัวโตสีฟ้าไซยาน มีขีดประกายสองข้าง** ใต้ลงมาเป็น
  **แคปซูลฟ้าน้ำเงินเขียนว่า "แนะนำเพื่อน" ต่อท้ายด้วยเลข "0.8%" ตัวโต**

## §2 พาเลต — ⚠️⚠️ **รอบนี้เป็น "ธีมสว่าง"** (light theme)

`src/assets/bg.json` ของดรอปนี้คือ `{"mode":"color","color":"#dbe6ff"}`
= **ฟ้าเพอริวิงเคิลอ่อน** — **bg.json คือแหล่งเดียวของพื้นเพจ ให้เปิดอ่านทุกรอบ
ห้ามสืบทอดค่าข้ามรอบ**

⚠️⚠️ **รอบก่อน (เงินทอง168) เป็นธีมมืด `#29210f` — รอบนี้กลับทิศ 180 องศา**
ใครเผลอทำตามรอบก่อนจะได้การ์ดสีน้ำตาลเข้มลอยอยู่บนพื้นฟ้าอ่อน
ทิศของรอบนี้คือ **เนื้อหา = การ์ดผิวสว่าง + หมึกเข้ม** ส่วน **โครม (navbar / footer /
ticker / Navfoot / CtaRedirect) = น้ำเงินอินดิโกเข้ม + ขอบฟ้าไซยาน**
→ รอบนี้ **หัว-ท้ายกับตัวหน้าอยู่คนละทิศจริง** (เข้ม vs สว่าง) ซึ่งต่างจากรอบก่อน
และ **บล็อก `<address>` ยัง paste verbatim ได้** เพราะ footer ยังเป็นผิวเข้ม

## §6 กฎที่บังคับโดย `tools/verify-build.mjs` (build แดงถ้าผิด)

- URL นอกโดเมน · `href` ชี้ route ที่ไม่มีจริง · `<h1>` ซ้ำในหน้าเดียว · `alt` หาย ·
  JSON-LD parse ไม่ผ่าน · canonical คนละโฮสต์ · meta description เกิน 200 ตัวอักษร ·
  `wrangler.toml` name ไม่ตรงโดเมน
- `<script>` ที่ไม่มี attribute เลยในหน้า indexable (= `define:vars` / `is:inline`)
- AVIF ที่ใหญ่กว่า WebP พี่น้องตัวเอง → **แก้ด้วยการ "ลด" quality เสมอ ไม่ใช่เพิ่ม**
- `color:` บน `<html>` จาก `BRAND_TEXT` หายไป
- `<address>` ที่ไม่มีชื่อแบรนด์ปัจจุบัน หรืออีเมลคนละโฮสต์กับ `site:`
- ไอคอนขนาดต่างๆ ใน `public/` ที่ไม่มีอะไรลิงก์ถึง
- emoji ตกแต่งที่ไม่ได้อยู่ใน element ที่มี `aria-hidden="true"`
- `href="#"` และ `onclick=`
- รูปที่ import แล้วไม่มีเวอร์ชันไหนถูก render
- **WARNING ไม่บล็อก และ "ห้ามไปไล่แก้" ระหว่างรีแบรนด์**

กฎอื่นที่ต้องถือไว้: ห้าม HTML comment (`<!-- -->`) ในไฟล์ที่ render ·
ห้าม `define:vars` · ห้ามเขียน `isActive` เอง (ใช้ `isActivePath` จาก `../lib/nav`) ·
ห้าม Swiper · ห้ามเติม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }` ·
JSON-LD ต้องมาจาก `pageGraph()` เท่านั้น และ **ห้าม** `Review` / `AggregateRating` /
`sameAs` / `address` / `PostalAddress` / `email` ใน graph ·
`<Image>`/`<Picture>` ต้องมี `widths` + `sizes` ที่ตรงกับความกว้างที่ **วาดจริง**
