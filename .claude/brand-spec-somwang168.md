### ⚠️ กับดักรอบนี้: สองแบรนด์ก่อนหน้าก็เป็นแดงเหมือนกัน

ห้ามตัดสินด้วยตาหรือด้วย "ตระกูลสี" เด็ดขาด — **grep เป็นค่าทีละตัว**
แดงรอบนี้ `#fa0513` ต่างจากแดงของ GT66B `#fb141b` และของ TKB55 `#fb131b`
แค่หลักเดียว การเจอ "แดงอยู่แล้ว" ในไฟล์ไหนจึงไม่พิสูจน์อะไรเลย

**สิ่งที่ทำให้รอบนี้ต่างจริงคือ "ทอง" กับ "พื้นดำอมแดง"** — GT66B เป็นแดง+โครเมียมขาว
บนดำสนิท `#000000` ส่วนรอบนี้เป็นแดง+**ทองไทย** บนพื้น `#290f0f`
⚠️ รอบนี้ **ไม่มีโครเมียมขาว/เงินเป็นสีระบบ ไม่มีม่วง ไม่มีน้ำเงิน ไม่มีฟ้า
ไม่มีเขียว ไม่มีส้ม ไม่มีชมพู** (สีเงินอมฟ้าในคำว่า "สมหวัง" บนโลโก้เป็น
รายละเอียดในรูป ห้ามดึงออกมาเป็นสีธีม — ที่ดึงออกมาคือ **ทอง** จากลายกนก)

```
<Announcement />                 ← chrome, ไม่มี heading
<LatestWinners />                ← chrome, ไม่มี heading
§1  ContentBoxPremium              as="h1"
§2  ContentBoxTwoNeumorphism       as="h2"   left=บรรทัด6 / right=บรรทัด7
§3  ContentBoxSevenThreeCyberCut   as="h2"   left=บรรทัด9 / right=<Picture slide1>
§4  ContentBox                     as="h3"   บรรทัด11
§5  ContentBoxNeumorphism          as="h3"   บรรทัด13
§6  ContentBox3ThreePremium        as="h2" heading={false}
                                   intro=บรรทัด15 · titleleft/center/right = ขั้นตอน 1/2/3
§7  ContentBoxTwoFloatingBadge     as="h2"   left=บรรทัด20 / right=บรรทัด21
§8  Faq4                           as="h2"   faqs={faqs}
<LoginRtpSection />              ← chrome
<ReviewCardSumo2 />              ← chrome
<Navfoot />                      ← chrome
```

`ContentBoxSevenThreeCyberCut` วาง **คอลัมน์ข้อความก่อน (7fr) รูปทีหลัง (3fr)**
รูปไปที่ `slot="right"` เสมอ หัวข้อจึงลงที่ prose ไม่ลงที่รูป และบนมือถือ
อ่านลำดับ หัวข้อ → ข้อความ → รูป

⚠️ `ContentBoxTwoFloatingBadge` (§7) — ก่อนใช้ให้เช็คสองอย่างตามที่ playbook สั่ง:
1. `whitespace-nowrap` บนป้ายหัวข้อ → ถ้ามี เปลี่ยนเป็น `w-[92%] max-w-2xl text-center`
2. ป้ายเป็น `absolute -top-6` → หัวข้อรอบนี้ยาว (`ช่องทางติดต่อแอดมิน … LINE
   OFFICIAL 24 ชม.`) จะตัดเป็น 2 บรรทัดบนมือถือแน่นอน ต้องคำนวณว่า
   `ความสูงป้าย − 24px` < `pt-*` ของการ์ด ถ้าไม่พอให้ขยับ `pt-*` ขึ้น
   และ **ต้อง sync ทั้งสามไฟล์ `*FloatingBadge`** ถ้าแก้ค่า padding

**LCP คือ hero ใน `MainLayout`** รูป slide1 ในหน้าจึงต้อง
`loading="lazy" fetchpriority="low" decoding="async"` และ
`formats={["avif","webp"]} fallbackFormat="webp" quality={80}`
— ห้ามจูน quality แยกตามฟอร์แมต (`tools/avif-quality-service.mjs` ทำให้เอง)
`widths` สูงสุดหยุดที่ **600** (ขนาดจริงของบิตแมป) และคุมภาพที่ `max-w-[600px]`

## §9 กฎที่ build บังคับ (verify-build.mjs จะแดง)

- `<h1>` ได้หน้าละ **หนึ่งตัว** — chrome ห้ามถือ heading ทุกระดับ
  (ticker, ฟีดผู้ถอน, การ์ดรีวิว, label คอลัมน์, ป้าย → `<p>`/`<span>` + `aria-label` ที่ section)
- `alt` ต้องบรรยายรูปจริง ไม่ใช่ `"bank"` / ตัวนับ
- ห้าม `href="#"` · ห้าม `onclick=` · ห้าม `define:vars` · ห้าม `<script>` ที่ไม่มี attribute
- ห้าม href ไปหา route ที่ไม่มีจริง (`/ตรวจหวย` `/แนวทาง` **ไม่มี route รอบนี้**)
- emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และเป็น **พี่น้อง**
  ของตัวหนังสือ ไม่ใช่อยู่ข้างใน
- AVIF ห้ามใหญ่กว่า WebP คู่ของมัน
- meta description ห้ามเกิน 200 อักขระ · หน้าย่อยเล็ง **150–160 อักขระ**
  (วัดด้วย `node -e "console.log([...s].length)"` ไม่ใช่ `wc -m` ซึ่งนับไบต์)
  ห้ามใส่ `&` ในสตริงนั้น
- ห้ามมี HTML comment `<!-- -->` ใน component ที่ถูก render (Astro ส่งออก dist ตรงๆ)
- `<address>` ที่ render ต้องมี `BRAND_NAME` ปัจจุบัน และอีเมลต้องเป็นโฮสต์ของ `site:`
- JSON-LD มาจาก `pageGraph()` เท่านั้น ห้ามเขียนมือ ห้ามใส่
  `Review` / `AggregateRating` / `sameAs` / `address` / `PostalAddress` / `email`
- ห้ามเอา `color:` ออกจาก `style` ของ `<html>` ใน `MainLayout`
- ห้ามแตะ `src/styles/_sources.generated.css` (build เขียนเอง)
- ห้ามเพิ่ม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`
- ห้ามเขียน `isActive` เอง — ใช้ `isActivePath` จาก `../lib/nav`
- ห้ามย้าย logic กลับเข้า `<script>` ใน component (`winnersFeed.ts` / `liveCounter.ts`)
- ห้ามใช้ `Math.random()` / `Date.now()` ใน frontmatter — ใช้ `brandPick`/`brandFlag`

## §10 หน้าเว็บรอบนี้

เปิดอยู่: `index` · `about-us` · `contact-us` · `promotion` · `ทดลองเล่น` ·
`ทางเข้า` · `login` · `register` · `terms` · `privacy` · `404`

ปิดอยู่ (`src/pages-disabled/`) — **ปล่อยไว้แบบนั้น**: `ตรวจหวย` · `แนวทาง`
(แบรนด์นี้เป็นสล็อต ไม่ใช่หวย) · `about-us` (สำเนาเก่า ไม่แตะ) ·
`login.redirect` · `register.redirect`

⚠️ `/ตรวจหวย` และ `/แนวทาง` **ไม่มี route** — ลิงก์ค้างในฟุตเตอร์/navbar
จะทำให้ build แดง `NavbarStyle7` และ `FooterPremium` เช็คแล้ว ไม่มีลิงก์ทั้งคู่
(ที่ grep เจอเป็นคอมเมนต์อธิบาย ไม่ใช่ `href`)

หน้าที่ **ไม่มีบทความ** (`h1×1 · h2×0 · h3×0`):
`/contact-us` · `/ทางเข้า` · `/promotion` · `/login` · `/register`
มีอะไรได้บ้างอ่านจาก playbook Phase 4.5 — บรีฟรอบนี้ไม่มีส่วน `SUB-PAGES`
ย่อหน้าทุกย่อหน้าบนหน้าพวกนี้จึงเป็นของที่รีแบรนด์รอบก่อนแต่งเอง
**ถ้าเจอ `<h2>` หรือย่อหน้าเกินโควตา ให้ลบ** นั่นคือการแก้ ไม่ใช่การเกินสโคป
