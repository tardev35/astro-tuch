## §7 กฎที่พังบ่อย — ย้ำ

- **chrome ห้ามมี heading tag ทุกระดับ** (navbar/footer/ticker/feed/รีวิว/ปุ่ม/
  ป้ายการ์ด) ป้ายที่เคยเป็น `<h*>` ให้เป็น `<p>`/`<span>` คลาสเดิม + `aria-label`
  บน `<section>`
- **ห้ามเหลือ HTML comment `<!-- -->`** ในไฟล์ที่ render (Astro ส่งออกจริง)
  คอมเมนต์อธิบายให้อยู่ใน frontmatter เท่านั้น
- **ห้ามใช้ `define:vars`** · ห้าม `href="#"` · ห้าม `onclick=` · ห้าม `Math.random()`
  ใน frontmatter
- emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และเป็น **พี่น้อง**
  ของป้ายชื่อ ไม่ใช่อยู่ในข้อความ · **ห้ามขึ้นต้น message ของ ticker ด้วย emoji**
- `isActive` ในทุก navbar ต้องมาจาก `isActivePath` ใน `../lib/nav`
- `<address>` ในฟุตเตอร์ **paste ตามต้นฉบับ ห้ามใส่เฮกซ์ของแบรนด์**
- ย่อหน้าในการ์ด: `text-left text-base leading-relaxed` + สีจากการ์ด
  **ห้ามใส่ `mx-auto` / `max-w-*` กับ `<p>` ในหน้า**
- `description` ที่เขียนเอง = **150–160 ตัวอักษร** (นับ "ตัวอักษร" ไม่ใช่ไบต์)
  ยกเว้นหน้าแรกที่ใช้บรรทัด Description ของบรีฟตรงตัว
- JSON-LD มาจาก `pageGraph()` เท่านั้น · ห้ามพิมพ์โดเมน · ห้ามต่อ URL ด้วย `+` ·
  ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address` / `email`
- **ห้ามรัน `npm run build`** — orchestrator รันครั้งเดียวตอน Phase 5
- **ห้าม deploy ห้าม `git push` ห้าม `git commit`**
