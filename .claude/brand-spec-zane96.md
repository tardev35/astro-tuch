  แนวนอน + overlay เต็มจอ)
- `FooterCyber` = **แผ่นที่ `clip-path` ตัดขอบบนเป็นหลังคาแหลมกลางจอ + ตารางเส้น
  พื้นหลัง + ปุ่มตัดมุมทแยง ไม่ render `BankStrip`** (รอบก่อน `FooterPremiumSumo`
  เป็นแผ่น `rounded-t-[3rem]` ออราเบลอสองขอบ กริด 5/3/4)
- ❌ **รอบนี้ไม่ใช้ `*FloatingBadge` สักตัว** (badge ยัง `whitespace-nowrap` และ
  H1 รอบนี้ยาว 51 ตัวอักษร จะล้น viewport มือถือ)
- ❌ **ไม่ใช้ `FeatureHighlights`** (render แต่ละข้อเป็น `<h3>` → h3 เกินเป้า)
- ❌ **ไม่ใช้ `SmoothCarousel`** (render `slide*` นอก SevenThree = ผิดกฎแข็ง)
- ✅ `ContentBox` ตัวฐานยังอยู่ในมิกซ์ เพราะเป็น **shared chrome** ที่ `terms` /
  `privacy` / `404` และหน้าย่อยอีก 7 หน้าใช้อยู่แล้วไม่ว่า index จะเลือกอะไร
- 🚨 **`BankStrip` ห้าม render ที่ไหนทั้งสิ้น** — บรีฟรอบนี้ไม่พูดถึงธนาคาร/วอลเลท/

## §8 กติกาที่ build บังคับ (อย่าให้แดง)

- emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และเป็น **พี่น้อง**
  ของข้อความ ห้ามฝังใน text prop (โดยเฉพาะ `message` ของ ticker)
- ห้าม `href="#"` · ห้าม `onclick=` · ปุ่มกลับขึ้นบนใช้ `href="#top"`
- `alt` ต้องบรรยายภาพจริง — ภาพตกแต่งซ้ำใช้ `alt=""` + `aria-hidden` บน wrapper
- FAQ ต้องเป็น `<details>`/`<summary>` ห้ามกลับไปเป็น button + max-height
- widget ที่หัวข้อเป็น `<p>` ต้องมี `aria-label` บน `<section>`
- ห้าม `define:vars` · ห้าม `<script>` ที่ไม่มี attribute บนหน้า indexable
- ห้ามเขียน `isActive` เอง — ใช้ `isActivePath` จาก `../lib/nav`
- ห้ามเขียน JSON-LD มือ — ใช้ `pageGraph()` จาก `../lib/schema`
  และ **ห้ามส่ง `Review` / `AggregateRating` / `sameAs` / `address` / `email`**
- ห้ามมี HTML comment (`<!-- … -->`) เหลือใน component ที่ render จริง
- `color: ${BRAND_TEXT}` บน `<html>` ใน `MainLayout` **ห้ามลบ**
- `<address>` ต้องมาจาก `BRAND_ADDRESS` เท่านั้น และ **paste verbatim ตาม SKILL.md
  ห้ามทาสีแบรนด์** (footer รอบนี้เป็นผิวเข้ม จึงใช้ค่าเดิมได้ตรงๆ)
- AVIF ต้องไม่ใหญ่กว่า WebP พี่น้องของตัวเอง (image service จัดการให้แล้ว)
- `description` ของทุกหน้า **ห้ามเกิน 200 ตัวอักษร** (เป้าจริง 150–160 ยกเว้นหน้าแรก)
