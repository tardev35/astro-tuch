## §6 — กฎที่ build บังคับ (verify-build.mjs จะแดงถ้าพลาด)

- หน้า indexable ห้ามมี `<h1>` ตัวที่สอง · ห้าม `href="#"` · ห้าม `onclick=` ·
  ห้าม `<script>` ที่ไม่มี attribute (= ห้าม `define:vars`) · ทุก `<img>` ต้องมี `alt`
  ที่บรรยายภาพจริง · JSON-LD ต้อง parse ได้ · canonical ต้องตรง host ·
  meta description ≤ 200 ตัวอักษร (เป้าที่เขียนเองคือ 150–160)
- emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และเป็น **พี่น้อง**
  ของ label ไม่ใช่อยู่ในข้อความ · **ห้ามมี emoji นำหน้าข้อความใน prop `message`**
- AVIF ห้ามใหญ่กว่า WebP คู่ของมัน → **ถ้าแดง ให้ลด `quality` ลง ห้ามเพิ่ม**
- icon ขนาดไหนที่ไม่มีใครลิงก์ = build แดง → **ห้ามเพิ่มไฟล์ใน `public/`**
- `<address>` ทุกตัวต้องมี `${BRAND_NAME}` และอีเมลต้องอยู่บน host ของ `site:`
  → มาจาก `BRAND_ADDRESS` เท่านั้น **ห้ามพิมพ์เอง ห้ามใส่สีแบรนด์ในบล็อกนั้น**
- `BRAND_ADDRESS` ต้องยังอ้าง `BRAND_NAME` · `<html>` ต้องยังมี `color: BRAND_TEXT`
- **ห้ามมี `<!-- ... -->` ในไฟล์ที่ render** (Astro ส่งขึ้น production ตรงๆ)
  → คอมเมนต์อธิบายอยู่ใน frontmatter (`// ...`) เท่านั้น
- `isActivePath` จาก `../lib/nav` เท่านั้น **ห้ามเขียน `isActive` เอง**
- JSON-LD ผ่าน `pageGraph()` เท่านั้น · **ห้ามใส่ `Review` / `AggregateRating` /
  `sameAs` / `address` / `PostalAddress` / `email`** · ห้ามพิมพ์โดเมน ห้ามต่อ URL ด้วย `+`
- ห้ามใส่ `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`
- `<p>` เนื้อความในหน้า **ห้ามมี `mx-auto` หรือ `max-w-*`** (การ์ดคุมความกว้างเองแล้ว)
- slot ของ `ContentBox*` รับได้ **1 element เท่านั้น** ถ้าต้องหลายบล็อกให้ห่อเองหนึ่งชั้น
