## §7 กฎที่ `verify-build.mjs` บังคับ (build แดงถ้าผิด) — อ่านก่อนแก้ไฟล์ไหน

1. `<h1>` ได้หน้าละ **1 ตัวเท่านั้น** บนหน้าที่ index ได้
2. **ห้าม `href="#"`** และ **ห้าม `onclick=`/`on*=`** — ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
3. **ทุก `href="/..."` ต้องชี้ route ที่มีจริง** — navbar/footer ที่หมุนมาใหม่มักมีลิงก์ค้าง
4. **ทุก `<img>` ต้องมี `alt` ที่บรรยายรูป** ไม่ใช่ชื่อไฟล์ ไม่ใช่ตัวนับ (`ภาพที่ 3`)
5. **emoji ทุกตัวต้องอยู่ใน element ที่มี `aria-hidden="true"`** และ **ห้าม emoji ใน prop ข้อความ** (ticker ฯลฯ)
6. **ห้าม `<script>` ที่ไม่มี attribute** บนหน้าที่ index ได้ → **ห้าม `define:vars`**
7. **ห้าม `Math.random()` / `Date.now()` / `new Date()` ใน frontmatter** → ใช้ `brandPick`/`brandFlag`
8. `meta description` 150–160 ตัวอักษร (**นับตัวอักษร ไม่ใช่ไบต์**) · เพดานแข็ง 200 ·
   **หน้าแรกได้รับยกเว้นเพดานล่าง** (description ของบรีฟรอบนี้ยาว ~119 ตัวอักษร — ship ตามนั้น **ห้ามต่อเติม**)
9. **canonical ต้องอยู่บนโฮสต์ `lotto189.com`** และ URL ใน JSON-LD ต้องตรงกับ canonical เป๊ะ
10. **ห้ามเขียน JSON-LD ด้วยมือ** ใช้ `pageGraph()` จาก `src/lib/schema.ts` เสมอ ·
    **ห้าม `Review` / `AggregateRating` / `sameAs` / `address` / `PostalAddress` / `email`**
11. **`color` ใน inline style บน `<html>` ต้องอยู่** (มาจาก `BRAND_TEXT`)
12. **ทุก `<address>` ที่ render ต้องมีคำว่า `LOTTO189`** และอีเมลต้องเป็น `@lotto189.com`
    → **ห้ามพิมพ์เอง** ใช้ `BRAND_ADDRESS` จาก `brandProfile.ts`
13. **รูปที่ import แต่ไม่มีหน้าไหน render = build แดง**
14. **AVIF ห้ามใหญ่กว่า WebP คู่ของมัน** — อย่าไปยุ่งกับ `tools/avif-quality-service.mjs`
15. `/terms` กับ `/privacy` ต้องมีเสมอ ห้ามปิด
16. ไอคอนใน `public/` ที่ไม่มีใครลิงก์ = build แดง

### กฎจาก playbook ที่ไม่ได้อยู่ใน gate แต่ยังบังคับ
- **ห้ามคอมเมนต์แบบ HTML (`<!-- -->`) ในไฟล์ที่ render จริง** — Astro ส่งขึ้น production ตรงๆ
  (คอมเมนต์ใน frontmatter / `{/* */}` ถูกตัดทิ้ง ไม่เป็นไร)
  → ตอนเขียนทับ component ใน Phase 3 ให้ลบคอมเมนต์ HTML เก่าในไฟล์นั้นไปด้วย
- **ห้ามเขียน `isActive` เอง ใน navbar** → `import { isActivePath } from "../lib/nav"`
- **ห้าม reintroduce Swiper** · **ห้ามย้าย logic กลับเข้า `<script>` ของ component**
  (`src/lib/nav.ts` · `liveCounter.ts` · `winnersFeed.ts`)
- **ย่อหน้าในกล่องเนื้อหา**: `text-left text-base leading-relaxed` + สีหมึก อยู่บน element
  ที่ถือ slot **ห้าม `text-sm`/`text-lg`** · **ห้าม `mx-auto max-w-*` บน `<p>` ในหน้า**
- **`text-center` ห้ามอยู่บนการ์ด/`<section>`** (มันตกทอดเข้าไปใน slot) ให้อยู่บนหัวข้อเอง
- **หนึ่ง slot = หนึ่ง element** ถ้าต้องหลายบล็อก ให้ห่อเองใน `<div>` เดียว
- **ห้ามใส่ `<style>` ที่มีแต่ `.font-sans { font-family: var(--font-sans) }`**
- **ห้ามลบ wrapper ที่ทำ layout จริง** และ **ห้ามเพิ่ม wrapper ใหม่** ใน `ContentBox*`
- **`<Image>`/`<Picture>` ต้องมี `widths` + `sizes` ที่ตรงกับความกว้างที่วาดจริง**
  และ **เฉพาะ hero เท่านั้น** ที่ได้ `loading="eager" fetchpriority="high"`
- **เมนู navbar ต้องมีไอคอนทุกรายการ** เป็น `<span aria-hidden="true">` ที่เป็น **พี่น้อง** ของ label
- **ลำดับเมนู**: `หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · <ที่เหลือ>`
