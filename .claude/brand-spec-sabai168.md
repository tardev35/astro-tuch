## §1 อาร์ตเวิร์กรอบนี้ (เปิดบิตแมปอ่านจริงแล้วทั้ง 4 ไฟล์)

ฉากรอบนี้คือ **ฟาร์ม/โรงเรือนปลูกผักกลางวันแดดจัด สว่างสดใส** ตรงข้ามกับรอบก่อนทุกประการ

**`banner1.png` (2172x724 แนวนอน — hero, MainLayout เป็นเจ้าของ ห้ามหน้าไหน import)**
โรงเรือนปลูกผักโครงไม้-โครงเหล็กกลางวัน แดดจัด ท้องฟ้าสว่าง
**ฝั่งซ้าย** ผู้หญิงผมบลอนด์สั้น สวมหมวกฟางปีกกว้าง เสื้อครอปลายสก็อตแดง-ขาวผูกปม
ทับด้วยเอี๊ยมยีนส์ นั่งข้างตะกร้าหวายใส่ผักกาด ข้าวโพด มะเขือเทศ · มี **รถแทรกเตอร์สีแดง**
อยู่ไกลๆ ริมซ้าย · ลังไม้ใส่ผลไม้
**ฝั่งขวา** ผู้ชายผมบลอนด์ สวมหมวกฟาง เสื้อเชิ้ตลายสก็อตแดงเปิดอก ทับเอี๊ยมยีนส์
ยืนพิงรั้วไม้ ถือลังไม้ใส่ข้าวโพดกับมะเขือเทศ · มี **หุ่นไล่กา** และ **ไก่** อยู่ด้านหลัง
**กลางภาพ** โลโก้ `สบาย168` ขนาดเล็กด้านบนสุด · ถัดลงมาเป็นข้อความสามมิติตัวโต
**`สบาย` สีทองคานารี + `168` สีฟ้าสกาย** · ใต้ลงมาเป็น **`สล็อตเบทต่ำสบายเป๋า`
ตัวอักษรไทยสามมิติสีทอง** · ใต้สุดเป็น **ป้ายไม้สีน้ำตาลเขียนว่า
`ทุนน้อย เล่นง่าย ยอดเข้าบริษัทโดยตรง`** · ใบไม้เขียวและดอกไม้เล็กๆ ประดับรอบ

**`banner1-mobile.png` (1080x1080 จัตุรัส)** — ฉากเดียวกันครอปสำหรับมือถือ
MainLayout pin ด้วย glob ของตัวเอง **ห้ามใส่ใน ContentBox ห้ามใช้เป็น hero ตรงๆ**

**`slide1.png` (540x600 แนวตั้ง)** — ป้ายไม้เขียนว่า **`แนะนำเพื่อน` + `0.8%`**
(เลข 0.8% เป็นสีฟ้าสกาย) คำว่า **`โปรโมชั่น`** เป็นตัวอักษรสามมิติสีทองตัวโต
โลโก้ `สบาย168` มุมซ้ายบน · คู่ชาย-หญิงชุดฟาร์มเดียวกัน · ดอกไม้ขาว ผักผลไม้
และ **กองเหรียญทอง** เต็มขอบล่าง → **§5 (แนะนำเพื่อน 0.8%)**

**`slide2.png` (540x600 แนวตั้ง)** — ป้ายไม้เขียนว่า **`คืนยอดเสีย` + `0.3%`**
องค์ประกอบอื่นเหมือน slide1 → **§4 (คืนยอดเสีย 0.3%)**

⚠️ **การจับคู่นี้อ่านจากตัวหนังสือบนรูปจริง ไม่ใช่จากเลขไฟล์** — uploader เขียนทับทุกดรอป

**ไฟล์ที่เป็นของแบรนด์เก่าและห้าม import เด็ดขาด** (eager import = emit ลง `dist/` ไม่ว่า render หรือไม่):

## §6 กฎที่บังคับโดย `tools/verify-build.mjs` (build จะแดง)

* **โครมห้ามถือ heading ทุกระดับ** — ticker, navbar, footer, ฟีดผู้ถอน, การ์ดรีวิว,
  ป้ายคอลัมน์, คำทักทาย ให้เป็น `<p>`/`<span>` ที่ถือคลาสเดิม + `aria-label` บน `<section>`
  ทุก `<h1>/<h2>/<h3>` ที่ขึ้นหน้าต้องสืบกลับไปที่หัวข้อใน docx ได้
  **`<h1>` ต้องมีหน้าละหนึ่งอันเท่านั้น**
* **ห้ามมีคอมเมนต์ HTML `<!-- -->`** ในไฟล์ที่ถูก render — Astro ส่งขึ้น production ตรงๆ
  (คอมเมนต์ใน frontmatter `//` ถูกตัดทิ้ง ใช้ได้ตามปกติ)
* **ห้าม `href="#"` ห้าม `onclick=`** · ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
* **อีโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`** และเป็น **พี่น้อง** ของ label
  ไม่ใช่อยู่ในข้อความ · **ห้ามใส่อีโมจินำหน้าข้อความ ticker** (prop ทำ aria-hidden ไม่ได้)
* **`alt` ต้องบรรยายรูป** ไม่ใช่ชื่อไฟล์/ลำดับ · รูปตกแต่งซ้ำใช้ `alt=""` + `aria-hidden` ที่ wrapper
* **FAQ เป็น `<details>`/`<summary>`** ห้ามกลับไปเป็น button + max-height
* **วิดเจ็ตที่หัวข้อเป็น `<p>` ต้องมี `aria-label` บน `<section>`** ห้ามเลื่อน `<p>` เป็น `h2` เพื่อแก้
* **ห้าม `define:vars`** บนหน้าที่ index ได้ · ห้าม render ฟีดเป็นคอนเทนเนอร์ว่างแล้วเติมด้วย JS
* **ห้ามเขียน `isActive` เอง** ใน navbar ให้ใช้ `isActivePath` จาก `../lib/nav`
* **ห้ามเขียน JSON-LD มือ** ใช้ `pageGraph()` จาก `src/lib/schema.ts` เท่านั้น
  ห้ามพิมพ์โดเมน ห้ามต่อ URL ด้วย `+` ห้ามใส่ `Review` / `AggregateRating` / `sameAs` /
  `address` / `PostalAddress` / `email`
* **AVIF ต้องไม่ใหญ่กว่า WebP พี่น้องของตัวเอง** — ถ้าแดงให้ **ลด** `quality` ไม่ใช่เพิ่ม
  (สไลด์รอบนี้เป็นฉากกลางแจ้งรายละเอียดจัด ใบไม้/ผัก/เม็ดเหรียญ → ใช้ `quality={64}`)
* **meta description ≤ 200 ตัวอักษร** (เป้า 150-160 ทุกหน้า ยกเว้นหน้าแรกที่ใช้ของบรีฟตรงตัว)
* **`<address>` ทุกอันที่ render ต้องมี `BRAND_NAME` ปัจจุบัน** และอีเมลต้องอยู่ที่โฮสต์ของ `site:`
  → มาจาก `BRAND_ADDRESS` เท่านั้น **ห้ามพิมพ์เอง**
* **`color:` บน `<html>` จาก `BRAND_TEXT` ห้ามหาย**

### กฎ house style ของเนื้อความ

* element ที่ถือ `<slot />` ได้ `text-left text-base leading-relaxed <สี>` —
  **ห้าม `text-sm` ห้าม `text-lg` กับย่อหน้า**
* หัวข้อจัดกลางได้ แต่ `text-center` ต้องอยู่ที่ **ตัวหัวข้อเอง** ห้ามอยู่บนการ์ดหรือ `<section>`
* **ห้ามใส่ `mx-auto` / `max-w-*` ให้ย่อหน้าในหน้าเพจ** — การ์ดคุมความกว้างเองแล้ว
* **หนึ่ง slot รับหนึ่ง element** ถ้าต้องมีหลายบล็อก ให้ห่อเองด้วย `<div>` เดียว
* **ห้ามเพิ่ม wrapper `<div>` รอบ slot กลับเข้าไป** ใน `ContentBox*` ที่แบนแล้ว
  (ใช้ `isolate` บนการ์ด + `-z-10` บนชั้นตกแต่ง `absolute`)
* ถ้าเปลี่ยนสีตัวอักษรของการ์ด ให้ **แทนที่** คลาสสีเดิม ไม่ใช่ใส่คลาสที่สองข้างๆ
* **ห้ามใส่ `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`**
  — Tailwind สร้างกฎนี้เองอยู่แล้ว และการมี `<style>` ทำให้ Astro แปะ `data-astro-cid-*`
  ลงทุก element ของ component นั้น
* `<strong>` ต้องครอบ **ทั้งก้อนคำที่คั่นด้วยช่องว่าง** (ภาษาไทยไม่มีช่องว่างระหว่างคำ
  ไฮไลต์ที่เริ่ม/จบกลางคำจะทำให้ formatter ตัดบรรทัดกลางคำ) · **ห้ามมี `<strong>` สองอัน
  ติดกันโดยไม่มีข้อความคั่น** · สีไฮไลต์มีค่าเดียวคือ **`#8a6504`**
