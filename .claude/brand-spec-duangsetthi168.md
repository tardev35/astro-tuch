## §2 พาเลต — ทองน้ำผึ้ง + แดงชาดจีน บนพื้นดำสนิท

อ่านจากอาร์ตเวิร์กจริงของดรอป 2026-10-20 (เปิดดูทุกไฟล์แล้ว):
โลโก้เป็น **หัวไฉ่ซิงเอี๊ย (เทพเจ้าโชคลาภจีน) ยิ้มหัวเราะ สวมหมวกทรงจีนสีแดงขลิบทอง
มีลูกปัดทองห้อยสองข้าง** ถัดมาเป็นคำว่า **"ดวงเศรษฐี" ตัวอักษรไทยสามมิติผิวทองมันวาว**
ต่อด้วย **เลข "168" สามมิติสีแดงสดขลิบทอง** บนพื้นโปร่งใส
แบนเนอร์เป็นฉาก **ห้องโถงหรูโทนขาว-งาช้าง** ฝั่งซ้ายเป็น **ชายหนุ่มผมสั้นสีเงิน
ชุดสูทขาว** นั่งพิงบัลลังก์ทอง ฝั่งขวาเป็น **หญิงสาวผมยาวสีเงิน ชุดรัดรูปขาว-ทอง
สวมสร้อยและกำไลทอง** รอบตัวมี **มงกุฎทอง กองเหรียญทอง ชิปคาสิโนดำ-ทอง
ไพ่เอซโพดำสีดำขลิบทอง** กลางภาพเป็นชื่อแบรนด์ตัวโต ใต้ลงมาเป็น
**เว็บสอนเล่นเกมออนไลน์** และ **แถบแดงโค้งเขียนว่า จากเศรษฐีพนันมือ1 พร้อมมงกุฎทอง**

⚠️ **พื้นเพจมาจาก `src/assets/bg.json` = `{"mode":"color","color":"#000000"}` = ดำสนิท**
ไม่ได้มาจากรูป (รูปพื้นขาว แต่พื้นเว็บดำ — ค่านี้เปิดดูแล้วทุกรอบ ห้ามสืบทอด)

⚠️ **ขนาดจริงของดรอปนี้ (วัดด้วย sharp แล้ว ห้ามเดา):**
`logo.webp` **500×500 จัตุรัส** · `banner1.png` **2243×701** · `banner1-mobile.png` **1080×1080** ·
`slide1.png` และ `slide2.png` **600×334 แนวนอน (ไม่ใช่จัตุรัส)** · `og.png` **1200×630**

⚠️ สไลด์กว้างสุด 600px จริง → candidate ที่เกิน 600 จะไม่ใช่พิกเซลจริง
ใส่ `max-w-[600px]` กันไม่ให้ขยายเกินบิตแมปตัวเอง และ **`alt` ห้ามเขียนว่า "รูปจัตุรัส"**
(สไลด์เป็นภาพแนวนอนอัตราส่วนราว 16:9)

⚠️ **`logo.webp` เป็นจัตุรัส 500×500 แต่เวิร์ดมาร์กกินความสูงแค่ราว 26% ตรงกลาง
(y ≈ 185–315) ที่เหลือเป็นพื้นโปร่งใส** — ถ้าใส่ `h-[50px] w-auto` แบบโลโก้แนวนอน
กล่องจะกลายเป็น 50×50 และตัวอักษรจะสูงแค่ ~13px อ่านไม่ออก
วิธีที่ใช้รอบนี้คือ **กล่องหน้าต่าง `overflow-hidden` กว้างตามที่ต้องการ แล้วให้รูป
กว้างเท่ากล่องและล้นบน-ล่างออกไปโดนตัด** (ส่วนที่ถูกตัดเป็นพื้นโปร่งใสล้วน)
`sizes` ต้องตรงกับความกว้างของ **กล่อง** ไม่ใช่ความสูง
⚠️ `quality={64}` ไม่ใช่ 80 — อาร์ตเวิร์กดรอปนี้เป็นภาพเกรนละเอียด (เหรียญทอง ประกาย
ผ้าซาติน ผิวคน ตัวอักษรไล่เฉดสามมิติ) ซึ่งเป็นทรงที่ AVIF ทำออกมาใหญ่กว่า WebP
`verify-build.mjs` จะ fail ถ้า AVIF ใหญ่กว่า WebP — **แก้ด้วยการลด quality เสมอ ไม่ใช่เพิ่ม**

**alt ต้องเขียนจากสิ่งที่อยู่ในรูปจริง** ของรอบนี้ (อ่านบิตแมปแล้ว):
ทั้งสองสไลด์เป็น **ฉากห้องโถงหรูโทนขาว-ทอง ชายหนุ่มผมสีเงินชุดสูทขาวฝั่งซ้าย
หญิงสาวผมยาวสีเงินชุดขาว-ทองฝั่งขวา มีมงกุฎทอง กองเหรียญทอง และกล่องของขวัญขาว-ทอง
ด้านบนเป็นโลโก้หัวไฉ่ซิงเอี๊ยกับชื่อแบรนด์ กลางภาพเป็นคำว่า "โปรโมชั่น" ตัวอักษรไทย
สามมิติสีทอง ใต้ลงมาเป็นแถบโค้งสีดำขลิบทอง** — slide1 เขียนว่า `แนะนำเพื่อน 0.8%`
และ slide2 เขียนว่า `คืนยอดเสีย 0.3%`

## §8 กฎที่ build บังคับ (ย่อ — รายละเอียดอยู่ใน SKILL.md)

- หัวข้อ `<h1>/<h2>/<h3>` ต้องมาจากบทความเท่านั้น **โครมห้ามถือ heading tag ทุกระดับ**
  (ticker, winners feed, review cards, footer columns, badge, card labels → `<p>`/`<span>`
  + `aria-label` บน `<section>`)
- `/contact-us`, `/ทางเข้า`, `/promotion`, `/login`, `/register` = **หน้าปุ่ม/หน้ารูป**
  → `h1×1 · h2×0 · h3×0` ห้ามเขียนหัวข้อย่อยหรือย่อหน้าอธิบาย
  (`/promotion` ได้ย่อหน้าเกริ่นหนึ่งย่อหน้า ~4 บรรทัดเท่านั้น)
- ห้ามมี HTML comment `<!-- … -->` ในไฟล์ที่ render (Astro ส่งมันขึ้น production ตรงๆ)
- อิโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และ **ห้ามฝังในข้อความ prop**
- ห้าม `href="#"` ห้าม `onclick=` ห้าม `define:vars` ห้ามเขียน `isActive` เอง
  (ใช้ `isActivePath` จาก `../lib/nav`)
- `alt` ต้องบรรยายรูปจริง ห้ามเป็น `"bank"` / `"ภาพที่ 3"`
- FAQ ต้องเป็น `<details>`/`<summary>` ห้ามกลับไปเป็นปุ่ม + `max-height`
- JSON-LD มาจาก `pageGraph()` เท่านั้น ห้ามเขียนมือ ห้ามใส่ `Review` `AggregateRating`
  `sameAs` `address`/`PostalAddress` `email`
- ที่อยู่/อีเมลมาจาก `BRAND_ADDRESS` เท่านั้น — ตั้ง `BRAND_NAME` แล้วเสร็จ ห้ามพิมพ์เอง
  footer ที่ใช้งานอยู่ **ต้อง** render บล็อก `<address>` (คัดลอกจาก SKILL.md แบบ verbatim
  **ห้าม theme ห้ามใส่ hex**)
- `<html>` ต้องคง inline `color:` ที่มาจาก `BRAND_TEXT` ไว้
- ห้ามแตะ `src/styles/_sources.generated.css` (build เขียนเอง)
- ห้ามเติม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`
- ห้ามแตะโครงสร้าง `<head>` ของ `MainLayout` (ลำดับบล็อกมาจาก `brandProfile`)
  และห้ามทิ้ง `?v=${iconVersion}` ออกจากลิงก์ไอคอน
