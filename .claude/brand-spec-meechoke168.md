## §2 พาเลตต์ — **ทองนำ · ชมพูบานเย็นเป็นฮิวที่สองจริง · พลัมเข้มเป็นเงา บนดำสนิท**

อ่านจากอาร์ตเวิร์กจริง: โลโก้เป็น **แมวกวักนำโชคสีขาว-ส้มทอง** นั่งอยู่เหนือคำว่า **มีโชค**
ที่เป็นตัวอักษรไทยหนาสามมิติไล่เฉด **ชมพูบานเย็น → ทอง** ต่อด้วยเลข **168** ทองสามมิติ
ล้อมด้วย **ริบบิ้นซาตินสีชมพูบานเย็น/มาเจนตา**, **เหรียญจีนทองรูสี่เหลี่ยม**, **ทองแท่งจีน**,
**หัวใจสีชมพู** และ **ดอกซากุระสีชมพู** บนพื้น **ดำสนิท** (`bg.json` = `{"mode":"color","color":"#000000"}`)
แบนเนอร์เป็นฉากเดียวกัน มีหญิงสาวผมเงินเกล้ามวยประดับซากุระ สวมชุดจีนชมพูปักทอง ถือเหรียญจีน
และมีธงชาติสิงคโปร์เล็กๆ ในป้ายบรรทัดล่าง

## §7 กฎที่ใช้กับทุกไฟล์ในรอบนี้

1. **ชื่อแบรนด์มาจาก `${BRAND_NAME}` เสมอ** ห้ามพิมพ์ `มีโชค168` ลงไปตรงๆ แม้แต่ใน `alt`
2. **ห้ามพิมพ์โดเมน** ที่ไหนทั้งสิ้น และห้ามต่อ URL ด้วย `+` — ใช้ `pageGraph()` อย่างเดียว
3. **ห้ามมี HTML comment `<!-- -->`** ในไฟล์ที่ render จริง (Astro ส่งออกไป dist/ ตรงๆ)
   คอมเมนต์อธิบายให้อยู่ใน frontmatter เท่านั้น
4. **`<strong>` ครอบช่วงที่คั่นด้วยช่องว่างทั้งช่วง** (ไทยไม่เว้นวรรคระหว่างคำ — เปิด/ปิด
   กลางคำจะทำให้บรรทัดตัดกลางคำ) และ `<strong>` สองตัวห้ามติดกัน
   สีไฮไลต์มีสีเดียวคือ **`#ffeaa0`**
5. **ย่อหน้าไม่ประกาศสีเอง** — การ์ด `ContentBox*` ตั้ง `text-left text-base leading-relaxed
   text-[#f6e4ee]` บน element ที่ถือ slot ให้แล้ว และ **ห้ามใส่ `mx-auto` / `max-w-*` กับย่อหน้า**
6. **หนึ่ง slot = หนึ่ง element** ห้ามยัดสอง block เข้า slot เดียว
7. **`description` 150–160 อักขระ** (นับอักขระ ไม่ใช่ไบต์ — วัดด้วย
   `node -e "console.log([...'…'].length)"`) **ยกเว้นหน้าแรก** ที่ใช้บรรทัด Description ของ
   บรีฟตรงตัว (134 อักขระ) ห้ามเติมให้ครบ · **ห้ามใส่ `&` ในสตริง description**
8. **ห้าม `href="#"` · ห้าม `onclick=` · ห้าม `define:vars` · ห้ามเขียน `isActive` เอง**
   (import `isActivePath` จาก `../lib/nav`) · ห้ามเอา Swiper กลับมา
9. **อีโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`** และเป็น sibling ของ label เสมอ
10. **`<h1>` มีได้หน้าละหนึ่งตัวเท่านั้น** chrome ห้ามถือ heading tag ทุกระดับ
11. **ห้ามรัน `npm run build`** — orchestrator รันครั้งเดียวใน Phase 5
12. **ห้ามลบ component variant ที่ไม่ได้ใช้** — เป็น inventory ของแบรนด์ถัดไป
13. **ห้ามแตะไฟล์ที่ไม่ได้อยู่ใน list ของตัวเอง** (ดู brief ของแต่ละ agent)

## §8 สถานะหน้าเว็บรอบนี้

`src/pages/` ที่มี: `404` `about-us` `contact-us` `index` `login` `privacy` `promotion`
`register` `robots.txt.ts` `terms` `ทดลองเล่น` `ทางเข้า`

- **`/ตรวจหวย` `/แนวทาง`** อยู่ใน `src/pages-disabled/` แล้ว → **ถูกต้องตามแบรนด์สล็อต
  ไม่ต้องย้าย** แต่ **ห้ามมีลิงก์ไปหาในไฟล์ที่ render จริง** (navbar/footer ที่ใช้งานอยู่)
- **`/login` `/register`** = **หน้าปุ่ม** (cta toggle เปิดอยู่) → `h1×1 h2×0`, ห้ามเขียนบทความ,
  **ห้ามแตะ `targetUrl`**, title/description เป็น 150–160 อักขระ, render `CtaRedirect`
- **`/ทางเข้า` `/contact-us`** = **หน้าปุ่ม** → `h1×1 h2×0 h3×0` ห้ามมีย่อหน้าอธิบาย
- **`/promotion`** = **หน้ารูป** → `h1×1 h2×0 h3×0` + ย่อหน้าเกริ่น ~4 บรรทัดเดียว + กริดรูป + CTA
- **`/about-us` `/ทดลองเล่น`** = **บทความจริง** หัวข้อมาจากเนื้อหาของหน้าเอง
- **`/terms` `/privacy` `/404`** = brand-neutral render ผ่าน `ContentBox` — ดึงชื่อจาก
  `BRAND_NAME` เอง **ห้ามใส่คลาสสีลงไปข้างใน**
- **`/ทางเข้า` ไม่อยู่ในเมนู navbar** (cta toggle เปิด → `/register` `/login` แทนที่) — ถูกแล้ว
- ไม่มีหน้าไหนมี `TODO(rebrand)` ค้าง (เช็กแล้ว)

**ลำดับเมนู navbar:** `หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · ทดลองเล่น ·
เกี่ยวกับเรา · ติดต่อเรา` (ทุกตัวมีไอคอน เป็น sibling span `aria-hidden`)
