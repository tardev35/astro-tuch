## §1 อัตลักษณ์แบรนด์ — อ่านจากอาร์ตเวิร์กจริง

**ยูฟ้า168 = เว็บพนันออนไลน์ครบวงจร แกนคือ "แทงบอล + สล็อต + บาคาร่า"**
บรีฟเรียกตัวเองว่า *"ฐานหลักเว็บพนันออนไลน์ แทงบอล เล่นสล็อต เว็บตรง100% ไม่ผ่านม้า"*

### โลโก้ (`logo.webp`)
พื้นโปร่งใส · **ลูกฟุตบอลขาว-ดำลายทอง** พร้อม **หางวงโคจรทองโค้ง** อยู่ซ้าย ·
คำว่า **"ยูฟ้า"** เป็น **ตัวอักษรไทยสามมิติผิวมันวาวสีทองเหลืองอร่าม ขอบเข้ม** ·
ต่อด้วยเลข **"168"** เป็น **ตัวเลขสามมิติผิวโครเมียมเงิน** — สองวัสดุคู่กัน

### แบนเนอร์ (`banner1.png`, แนวนอน) และ `banner1-mobile.png`
**ฉากอัฒจันทร์สนามฟุตบอลกลางคืน** ไฟสปอตไลต์ส่องจากหลัง พื้นหลังเกือบดำ ·
ฝั่งซ้ายเป็น **ผู้หญิงผมบลอนด์ ชุดกีฬาดำ-ทอง ถือลูกฟุตบอลขาว-ดำ** มีมงกุฎทอง
เล็กและ **ตู้สล็อต 777 ทอง** ที่มุมล่างซ้าย · ฝั่งขวาเป็น **ผู้ชายผมบลอนด์
เสื้อบอลดำ-ทอง** ยืนข้าง **ลูกฟุตบอลทองคำใบใหญ่** · กลางภาพเป็น **ข้อความ

### กฎการใช้ — จำให้ได้สามข้อ
1. **`<strong>` ในเนื้อความใช้ `#fee45d` ตัวเดียว** (14.8:1 บนการ์ด) —
   ห้ามใช้ `#b8780d` หรือ `#7a4e05` กับตัวอักษรขนาดเนื้อความ
2. **ปุ่ม CTA หลัก** = พื้นถมไล่เฉดทอง `#fee45d → #e6a416 → #b8780d`
   **+ ตัวอักษร `#140e02`** (15.1 / 8.7→ok / 5.3:1 ผ่านทุก stop)
   **ห้ามสลับเป็นพื้นทองแล้วใส่ตัวอักษรขาว**
3. **ปุ่ม CTA รอง** = พื้นถมไล่เฉดเงิน `#e8ecf1 → #a8b2bf → #78828f`
   **+ ตัวอักษร `#0b0d10`** · หรือแบบ outline: ขอบ `#e6a416` ตัวอักษร `#fee45d`
   บนพื้น `#0a0908`

## §8 กฎที่ยังบังคับอยู่ (สรุปจาก playbook — อ่านรายละเอียดเต็มใน SKILL.md)

- `isActive` ต้องมาจาก `isActivePath` ใน `../lib/nav` **ห้ามเขียนเอง**
- **ห้ามมี HTML comment `<!-- -->`** ในไฟล์ที่ render จริง (Astro ส่งขึ้น production)
- **chrome ห้ามปล่อย heading tag ทุกระดับ** — ticker, winners feed, review
  ledger, card label ใช้ `<p>`/`<span>` + `aria-label` บน `<section>`
- **อีโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`**
- **ห้าม `href="#"` ห้าม `onclick=`** · ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
- **FAQ ใช้ `<details>`/`<summary>`** ห้ามกลับไปเป็น button + max-height
- **ห้าม `define:vars`** บนหน้า indexable
- **ห้ามเขียน JSON-LD เอง** — เรียก `pageGraph()` จาก `src/lib/schema.ts`
  และ **ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address` / `email`**
- **ห้ามลบ `color:` จาก `<html>` style ใน MainLayout** (มาจาก `BRAND_TEXT`)
- **ห้ามเติม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`**
- **ย่อหน้าในการ์ด:** `text-left text-base leading-relaxed` + สีจากการ์ด
  **ห้ามใส่ `mx-auto` / `max-w-*` บน `<p>` ในหน้า**
- **`description` ที่เขียนเอง 150–160 ตัวอักษร** (นับ character ไม่ใช่ byte)
  — ยกเว้นหน้าแรกที่ใช้ของบรีฟตรงตัว
- **หน้าปุ่ม/หน้ารูป `h2 ×0`:** `/contact-us` · `/ทางเข้า` · `/promotion` ·
  `/login` · `/register`
- `BRAND_ADDRESS` มาจาก `BRAND_NAME` เอง **ห้ามพิมพ์เอง** · บล็อก `<address>`
  ใน footer **paste verbatim ห้ามใส่สีแบรนด์ลงไป**
