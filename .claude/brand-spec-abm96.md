## §1 ทิศของธีมรอบนี้

**เนื้อหาสว่าง (ชมพู) + โครมเข้ม (พลัม)** — ทิศเดียวกับรอบก่อน แต่ **คนละตระกูลสีทั้งชุด**

- พื้นเพจมาจาก `src/assets/bg.json` = `{"mode":"color","color":"#f8b9f0"}` = **ชมพูพาสเทลอิ่มตัว**
  (รอบก่อน LOTTOPLUS เป็น `e1fef3` เขียวมินต์จาง — **คนละตระกูลสี ห้ามสืบทอดค่า**)
- 🚨🚨 **พื้นเพจรอบนี้อิ่มตัวกว่ารอบก่อนมาก** (`f8b9f0` ไม่ใช่ขาวอมสี) — หมึกบนพื้นเพจตรงๆ
  ต้องเข้มจริง และ **ตัวอักษรขาวบนพื้นเพจได้แค่ 1.6:1 = ห้ามเด็ดขาด**
- การ์ดเนื้อหาเป็นผิวขาว/ขาวอมชมพู · navbar/footer/ticker/Navfoot เป็นผิวพลัมเข้ม
- ⚠️ **สองโซนคนละทิศ** — หมึกเข้มในโซนเนื้อหา หมึกสว่างในโครม **จุดที่พลาดง่ายที่สุด**

## §7 title / description ของแต่ละหน้า

- **หน้าแรก** — คัดจากบรีฟ **verbatim** (content.txt บรรทัด 1-2) **ห้ามต่อเติมให้ครบ 150**
  `verify-build` ยกเว้นเพดานล่าง 150 ให้หน้าแรกไว้ด้วยเหตุผลนี้โดยเฉพาะ
  - title = `ABM96 เว็บเอเอ็มบีคาสิโน บาคาร่า สล็อต รูเล็ต ไฮโล รวมครบวงจร`
  - description = `ABM96 เว็บเอเอ็มบีคาสิโน แหล่งเดิมพันเกมออนไลน์ บาคาร่า สล็อต รูเล็ต ไฮโล เริ่มต้น1บาท มีไลฟ์เล่นได้ 24 ชั่วโมง และเกมอื่นๆ ครบวงจร`
  - H1 = `ABM96 เว็บเอเอ็มบีคาสิโน แหล่งเดิมพันเกมออนไลน์ ครบทุกแนว` (บรรทัด 3 — **ต่างจาก title ห้าม copy**)
- **หน้าย่อยทุกหน้า** — บรีฟ **ไม่มี** ส่วน `SUB-PAGES (Title & Meta Description)`
  → เขียนเองจากบรีฟ **ความยาว 150-160 ตัวอักษร (นับ character ไม่ใช่ byte)**
  🚨 ที่พลาดทุกรอบคือ **ยาวเกิน** เพราะเติมอนุประโยคไปเรื่อยๆ — เขียนประโยคเดียวที่บอกว่า
  หน้านั้นมีไว้ทำอะไร แล้วหยุด
- ทุกหน้าเรียก `pageGraph()` และส่ง `description` **สตริงเดียวกัน** กับที่ส่งให้ `MainLayout`
- ทุกหน้า **ยกเว้นหน้าแรก** ส่ง `breadcrumb`

## §8 กฎที่ build บังคับ (ละเมิด = build แดง)

- ❌ `href="#"` และ `onclick=` — ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
- ❌ `<h1>` ตัวที่สองในหน้าเดียว · `alt` ที่หายไปหรือไร้ความหมาย (`"logo"`, `"banner1"`, `"…ภาพที่ 3"`)
- ❌ อีโมจิที่ไม่ได้อยู่ใน element ที่มี `aria-hidden="true"` — และ **ห้ามฝังอีโมจิใน prop ข้อความ**
  (mark ไม่ได้) โดยเฉพาะต้นข้อความ `Announcement5`
- ❌ `define:vars` / `<script>` ไร้ attribute บนหน้าที่ index ได้
- ❌ `new Date()` / `Math.random()` / `Date.now()` ใน **frontmatter** ของ `.astro`
- ❌ URL นอกโดเมน (allowlist: `yoalink.com` `tinyurl.com` `schema.org` `www.w3.org` + fonts)
- ❌ `href` ชี้ route ที่ไม่มีจริงใน `dist/` 🚨 **จุดนี้คือที่ที่ลิงก์ `/ตรวจหวย` `/แนวทาง` ที่ค้างจะโผล่**
- ❌ `description` เกิน 200 ตัวอักษร · AVIF ที่ใหญ่กว่า WebP พี่น้องตัวเอง
- ❌ `<address>` ที่ไม่มี `BRAND_NAME` ปัจจุบัน หรืออีเมลที่โฮสต์ไม่ตรง `site:`
- ❌ JSON-LD ที่ parse ไม่ผ่าน · `Review` / `AggregateRating` / `sameAs` / `PostalAddress` ใน JSON-LD
- ❌ `color:` บน `<html>` ที่หายไป (มาจาก `BRAND_TEXT`)
- ❌ รูปที่ import แล้วไม่มีหน้าไหน render
- ⚠️ **WARNINGS ไม่บล็อก build และ "ห้ามไปไล่แก้ระหว่างรีแบรนด์"**

## §9 กฎโครงสร้างที่ต้องคงไว้

- ✅ `<!-- HTML comment -->` **ห้ามมีในไฟล์ที่ render** — Astro ส่งขึ้น production ตรงๆ
  (คอมเมนต์ `//` ใน frontmatter ปลอดภัย)
- ✅ ย่อหน้าในหน้า **ห้ามมี** `mx-auto` / `max-w-*` — การ์ดคุมความกว้างเองแล้ว
- ✅ `ContentBox*` ทุกใบ: element ที่ถือ `<slot />` ต้องมี `text-left text-base leading-relaxed` + สีหมึก
  **ห้ามใส่ `text-center` บนการ์ดหรือ `<section>`** (จะ inherit ลง slot)
- ✅ **ห้ามเพิ่ม wrapper `<div>` รอบ slot กลับมา** — ทุกไฟล์ flatten แล้ว (`isolate` + `-z-10`)
- ✅ navbar ใช้ `isActivePath` จาก `../lib/nav` **ห้ามเขียน `isActive` เอง**
- ✅ ลำดับเมนู: `หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · <ที่เหลือ>` ทุกเมนูมีไอคอนใน
  `<span aria-hidden="true">` ที่เป็น **พี่น้อง** ของป้ายชื่อ
- ✅ `Faq*` เป็น `<details>`/`<summary>` ห้ามกลับไปเป็น button + max-height
- ✅ `LatestWinners*` อ่าน `src/lib/winnersFeed.ts` · rows server-render จาก `brandPick`/`brandFlag`
  **ห้ามกลับไป `<script define:vars>` และห้ามใช้ `Math.random()`** · คง `data-winner-*` hooks ไว้
- ✅ `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }` **ห้ามใส่กลับ**
- ✅ `MainLayout` `<head>` — **ห้ามจัดเรียงใหม่ ห้ามเติม tag ห้ามใส่ `google-site-verification`**
- ✅ `?v=${iconVersion}` บนลิงก์ไอคอน **ห้ามถอด**
- ✅ บล็อก `<address>` ใน footer **paste verbatim ห้ามทาสี** (`border-white/15` + `bg-black/20`)
  — footer รอบนี้เป็นผิวเข้ม จึงลงตัวอยู่แล้ว
