อ่านจากอาร์ตเวิร์กดรอป 2026-10-11 จริง + `src/assets/palette.json`:
โลโก้คือ **ถ้วยแชมป์ทอง + ลูกฟุตบอลทอง** มีตัวอักษร `UFA` ทองและ `324` **เงินโครเมียม**

### กฎที่ยังมีผลกับทุก variant

- **ห้ามลบไฟล์ variant ที่ไม่ได้ใช้** — เป็น inventory ของแบรนด์ถัดไป
  สีของแบรนด์เก่าที่ค้างอยู่ในไฟล์ที่ **ไม่ได้ render** = drift ที่คาดไว้ ไม่ใช่บั๊ก
- ไฟล์ที่ **render จริง** ต้องถูก retheme ทั้งไฟล์ + ลบคอมเมนต์ `<!-- ... -->`
  (Astro ส่ง HTML comment ลง dist จริง)
- `*FloatingBadge`: เช็ก `whitespace-nowrap` บนป้ายหัวข้อ (ต้องไม่มี — ใช้ width cap
  แทน) และเช็กว่า `pt-*` ของการ์ดพอให้ป้าย 2 บรรทัดไม่ทับเนื้อหา

## §8 — กฎโครงสร้างที่ bindings ทุก agent

1. **หัวข้อมาจากเนื้อหาเท่านั้น** โครม (navbar/footer/ticker/winners feed/
   login widget/review card/การ์ด label/caption) **ห้ามใช้ `<h1>`–`<h6>` ทุกระดับ**
   ใช้ `<p>`/`<span>` คลาสเดิม + `aria-label` บน `<section>` แทน
   `verify-build` ทำให้ build แดงถ้ามี `<h1>` ที่สองในหน้าที่ index ได้
2. **ห้ามใส่ HTML comment `<!-- -->`** ในหน้า/คอมโพเนนต์ที่ render — Astro ส่งลง
   dist จริง เวลา retheme คอมโพเนนต์ ให้ลบคอมเมนต์ที่มีอยู่เดิมออกด้วย
   (คอมเมนต์ใน frontmatter `//` ถูกตัดทิ้ง ใช้ได้ตามปกติ)
3. **ย่อหน้าชิดซ้าย `text-left text-base leading-relaxed`** เสมอ หัวข้อ center ได้
   แต่ต้องใส่ `text-center` ที่ตัวหัวข้อ ไม่ใช่ที่การ์ด/`<section>`
   **ห้ามใส่ `mx-auto max-w-4xl` บน `<p>`** ในหน้า — การ์ดคุมความกว้างเองแล้ว
4. **หนึ่ง slot = หนึ่ง element** ถ้าต้องหลายย่อหน้าให้ห่อเองเป็น `<div>` เดียว
   **ห้ามเติม wrapper `<div>` กลับเข้าไปใน component** (ทุกตัว flatten แล้ว)
5. **สีใน `terms`/`privacy`/`404` ห้ามประกาศเอง** — inherit จาก `ContentBox`
6. **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`**
   ห้ามมี emoji ในสตริง `message` ของ ticker
7. **ห้าม `href="#"` ห้าม `onclick=`** ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
8. **`alt` ต้องบรรยายรูปจริง** (ดู §4) ห้ามเป็น `"bank"` / `"ภาพที่ 3"`
9. **FAQ ต้องเป็น `<details>`/`<summary>`** ห้ามกลับไปเป็น button + max-height
10. **ห้าม `define:vars`** / ห้าม `<script>` ที่ไม่มี attribute ในหน้าที่ index ได้
11. **JSON-LD มาจาก `pageGraph()` เท่านั้น** ห้ามพิมพ์โดเมน ห้ามต่อ URL ด้วย `+`
    ห้ามเพิ่ม `Review` / `AggregateRating` / `sameAs` / `address` / `PostalAddress`
    / `email`
12. **`isActivePath` จาก `../lib/nav`** ห้ามเขียน isActive เอง
13. **`<address>` block ใน footer**: วางตามเทมเพลตใน SKILL.md **เป๊ะๆ ห้ามทาสี**
    (`border-white/15` `bg-black/20` + opacity) และอ่านจาก `BRAND_ADDRESS`
14. **description 150–160 ตัวอักษร** (นับ **อักขระ** ไม่ใช่ไบต์ — ใช้
    `node -e "console.log([...'...'].length)"`) ยกเว้นหน้าแรกที่ใช้บรรทัด
    `Description` ของบรีฟตรงตัว (**ยาว 133 ตัวอักษร ห้ามเติมให้ครบ 150** —
    orchestrator ตั้งเป็นค่า default ใน `MainLayout` ไว้แล้ว และ verify-build
    ยกเว้นเพดานล่างให้หน้าแรกโดยเฉพาะ) — **หน้าย่อยทุกหน้ายังต้อง 150–160**
    **ห้ามใส่ `&`** ในสตริง description (Astro escape เป็น `&#38;` = นับ 5 ตัว)
15. **`/contact-us` · `/ทางเข้า` · `/promotion` · `/login` · `/register` ไม่มีบทความ**
    → `h1×1 h2×0 h3×0` ทุกหน้า เจอ `<h2>` แปลว่าต้องลบ prose ไม่ใช่ลดระดับแท็ก
16. **`<Image>`/`<Picture>` ต้องมี `widths` + `sizes` ที่ตรงกับความกว้างที่ "วาดจริง"**
    `quality` ปล่อยไว้ที่ค่าบ้าน — `tools/avif-quality-service.mjs` rescale AVIF
    ให้เอง ห้าม hand-tune ต่อ format
17. **`npm run build` เป็นของ orchestrator เท่านั้น** subagent **ห้ามรัน build**
