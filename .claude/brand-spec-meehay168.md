## §2 — พาเลท (อ่านจากอาร์ตเวิร์กจริง + `palette.json`)

โลโก้: คำว่า **"มี" เป็นตัวอักษรไทยหนาสามมิติสีขาวมุกตัดขอบเทา** ต่อด้วย **"เฮ168" สีแดงชาดบับเบิลผิวมันวาว**
ทางซ้ายเป็น **หน้ายิ้มหัวเราะสีเหลืองทองแก้มชมพู** นั่งบน **กองเหรียญทอง** ล้อมด้วย **ประกายดาวสีทอง** และ **ขีดประกายสีแดง** บนพื้นขาว
แบนเนอร์/สไลด์: ฉาก **พื้นขาว-ชมพูอ่อน** มี **หญิงสาวผมบลอนด์เงินชุดลูกไม้ขาวแต่งโบว์แดง ชี้นิ้วมาทางผู้ชม** · **มือถือขึ้นวงล้อสล็อต** · **หัวใจแดง** · **กล่องของขวัญขาวผูกโบว์แดง** · **เหรียญทองร่วง** · **จอยเกมสีแดง** · **มงกุฎทอง**

`palette.json` ให้ `logo.webp` vivid = `#fb1b32` `#fb2a3c` `#f41332` → **ตัวเลขชี้ถูกเฉพาะไฟล์โลโก้**
ส่วน `banner1.png` / `slide1.png` ให้ dominant เป็น **ขาวเกือบสนิท** (`#fefefd` `#fefefe`) เพราะฉากเป็นพื้นขาว
และ vivid เป็นโทนผิว/ชมพูจาง (`#f3d3cc` `#fbe3e2`) — **ทั้งคู่ไม่ใช่สีแบรนด์ และไม่ใช่สีพื้นเพจ**
ทองอำพัน/เหลืองทองอ่านจากหน้ายิ้มกับกองเหรียญ ซึ่ง `palette.json` ไม่จัดอันดับให้เพราะพื้นที่น้อย
(สุ่มพิกเซลยืนยัน: `#fc1830` `#fc243c` เป็นก้อนใหญ่สุดของโลโก้ และ `#fcd860` `#fcd854` `#fccc48` เป็นก้อนทอง)

## §7 — กฎที่ build บังคับ (สรุปสั้น — รายละเอียดเต็มอยู่ใน SKILL.md)

1. **โครม (navbar/footer/ticker/feed/widget/การ์ด/ป้าย) ห้ามใช้แท็ก `<h1>`–`<h6>` ทุกระดับ** ให้ใช้ `<p>`/`<span>` คลาสเดิม + `aria-label` บน `<section>`
2. `<h1>` มีได้หน้าละ **หนึ่ง**
3. อีโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และ **ห้ามอยู่ใน text prop** (เช่นต้นข้อความ ticker)
4. ไอคอนเมนู navbar ต้องเป็น **sibling** ของ label ไม่ใช่อยู่ในข้อความ
5. ลำดับเมนู: `หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · <ที่เหลือ>` (รอบนี้ cta toggle เปิด → **ไม่มี `/ทางเข้า` ในเมนู** แต่ footer ลิงก์ได้)
6. `alt` ต้องบรรยายรูปจริง ไม่ใช่ `"bank"` / `"ภาพที่ 3"`
7. ห้าม `href="#"` ห้าม `onclick=` ห้าม `define:vars` ห้าม `<script>` ที่ไม่มี attribute
8. ห้ามเขียน `isActive` เอง — `import { isActivePath } from "../lib/nav"`
9. FAQ ต้องเป็น `<details>`/`<summary>` ไม่มี `<script>`
10. **ห้ามมี HTML comment `<!-- -->`** ในไฟล์ที่ render (Astro ส่งออกตรงๆ) — คอมเมนต์อธิบายให้อยู่ใน frontmatter
11. JSON-LD มาจาก `pageGraph()` เท่านั้น · ห้าม `Review` / `AggregateRating` / `sameAs` / `address` / `email` ใน graph
12. `color: ${BRAND_TEXT}` บน `<html>` ของ `MainLayout` **ห้ามลบ**
13. `<address>` ใน footer: paste ตามบล็อกใน SKILL.md **ห้ามใส่เฮกซ์ของแบรนด์ลงไป**
14. `description` ที่เขียนเอง = **150–160 ตัวอักษร** (นับตัวอักษร ไม่ใช่ไบต์) · หน้าแรกใช้ของบรีฟตรงตัว
15. ห้ามใส่ `mx-auto max-w-4xl` บน `<p>` ในหน้า — การ์ดคุมความกว้างเองแล้ว
16. ย่อหน้าในการ์ด = `text-left text-base leading-relaxed` เสมอ · หัวข้ออาจ center ได้แต่ต้อง center ที่หัวข้อเอง
17. **หนึ่ง element ต่อหนึ่ง slot**
18. ห้ามเพิ่ม wrapper `<div>` กลับเข้าไปใน `ContentBox*` ที่ flatten แล้ว
19. ห้ามใส่ `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`
20. ห้าม build เอง (orchestrator build ครั้งเดียวใน Phase 5)
