## §2 — พาเลตต์ (มังกรแดง + โครเมียมขาว บนดำสนิท)

อ่านจากอาร์ตเวิร์กดรอป 2026-10-13 จริง:

- **โลโก้** — อักขระมังกรจีน 龍 เขียนด้วยพู่กันสีแดงสด อยู่ซ้ายสุด ต่อด้วยเวิร์ดมาร์ก
  `GT66B` ที่ **GT เป็นโครเมียมขาวสามมิติ** · **66 เป็นแดงสดไล่เฉด** · **B เป็นโครเมียมขาว**
  พื้นโปร่งใส
- **banner1** — ฉากคาสิโนสตูดิโอ **ดำสนิท** ส่องด้วยริบบิ้นแสง **แดง** ชายหนุ่มผมขาวเงิน

**ไม่มีทอง (เกินมงกุฎเล็กบนป้ายสไลด์) ไม่มีม่วง ไม่มีชมพู ไม่มีน้ำเงิน ไม่มีฟ้า

## §7 — คำศัพท์: ใช้คำของบรีฟรอบนี้เท่านั้น

**เว็บนี้คือคาสิโน** คำเกมที่มีได้มีสามคำ: **บาคาร่า · ไฮโล · สล็อต**
(ตามบรีฟ — ไม่มี "บอล/กีฬา" รอบนี้)

กรอบเรื่องของบรีฟรอบนี้: `คาสิโนเซิร์ฟนอก` · `เซิร์ฟเวอร์ต่างประเทศ` ·
`เกมถูกลิขสิทธิ์` · `ค่ายเกมระดับเอเชีย` · `ได้มาตรฐาน` · `แพลตฟอร์มเดียว` ·
`หมวดเกม` · `เมนูค้นหาเกม` · `ตรวจสอบเครดิต` · `จัดการบัญชีสมาชิก` · `เกมไพ่` ·
`ลูกเต๋า` · `เกมวงล้อคลาสสิก` · `ฟรีสปิน` · `โบนัสตัวคูณ` · `ฟีเจอร์พิเศษ` ·
`ตารางจ่าย` · `ช่วงเดิมพัน` · `กติกา` · `โบนัสคืนยอดเสีย 0.3%` · `เข้ายูสทุกวัน` ·
`รอบประจำวัน` · `เวลาตัดยอด` · `ยอดที่เข้าเกณฑ์` · `แนะนำเพื่อน` · `โบนัส 0.8%` ·
`ไม่จำกัด` · `ลิงก์แนะนำ` · `สมัคร 3 ขั้นตอน` · `ยืนยันบัญชี` · `แอดมิน` ·
`24 ชั่วโมง` · `รหัสผ่าน` · `PIN` · `OTP` · `เอกสารรับรองที่ตรวจสอบได้`

⚠️ **แบรนด์รอบก่อน TKB55 ขาย `เว็บคาสิโนไทย` / `ยอดเข้าบริษัทโดยตรง` /
`ฝากถอนทุกธนาคาร` / `บอลออนไลน์`** — บรีฟรอบนี้**ไม่มีกรอบนั้นเลยสักคำ**
ห้าม find-and-replace ทับประโยคเก่า ให้เขียนใหม่จากบรีฟ

**ไม่มีคำเกี่ยวกับหวยที่ไหนทั้งสิ้น**

**ห้ามอ้างสิ่งที่บรีฟไม่ได้ระบุ:** เลขใบอนุญาต ชื่อหน่วยงานกำกับ ชื่อค่ายเกมจริง
ชื่อนิติบุคคล ชื่อธนาคาร ยอดฝากขั้นต่ำ ค่า RTP จำนวนสมาชิก ปีก่อตั้ง หรือประเทศ
ที่ตั้งเซิร์ฟเวอร์ที่เจาะจงกว่าคำว่า "ต่างประเทศ" ตัวเลขที่มีได้มีสามตัว:
**0.3% · 0.8% · 24 ชั่วโมง**

⚠️ **บรีฟรอบนี้ตั้งคำถามกับคำโฆษณาของตัวเองถึงห้าจุด และทุกจุดต้องขนมาด้วย
ห้ามตัดทิ้งเพราะฟังดูไม่ขายของ:**
1. ข้อมูลเซิร์ฟเวอร์ต่างประเทศ/ลิขสิทธิ์เกม/มาตรฐาน **ควรมีรายละเอียดผู้ดำเนินงาน
   หรือเอกสารรับรองที่ตรวจสอบได้ประกอบ**
2. ค่ายเกมระดับเอเชีย **ควรมีรายชื่อผู้พัฒนาและข้อมูลการให้บริการที่ชัดเจน** และ
   **ไม่มีเกมประเภทใดรับประกันผลกำไร**
3. คำว่า **ไม่จำกัด** ควรระบุให้ชัดว่าหมายถึงอะไร
4. ผู้สมัคร **ควรตรวจสอบชื่อโดเมน ข้อมูลผู้ดำเนินงาน และข้อกำหนด** ก่อนส่งข้อมูล
   ส่วนตัว รวมถึง **ตรวจสอบอายุและข้อกฎหมายในพื้นที่ของตน**
5. **ไม่ควรเปิดเผยรหัสผ่าน PIN หรือ OTP** แม้ผู้ติดต่อจะอ้างว่าเป็นเจ้าหน้าที่

## §8 — กฎที่ build บังคับ (ย้ำเฉพาะตัวที่พลาดบ่อย)

- **ห้ามพิมพ์ชื่อแบรนด์ลงหน้าเว็บตรงๆ** — interpolate `${BRAND_NAME}` เสมอ
- **ห้ามพิมพ์โดเมน** และห้ามต่อ URL ด้วย `+` — JSON-LD มาจาก `pageGraph()` ตัวเดียว
- **ห้ามมี `<!-- ... -->`** ในไฟล์ที่ render — Astro ส่งออกไปที่ HTML จริง
  (คอมเมนต์อธิบายไปอยู่ใน frontmatter เท่านั้น)
- **`<h1>` ได้หน้าละหนึ่งตัว** และ **chrome ห้ามถือ heading ทุกระดับ** — ticker,
  winners feed, การ์ด, ป้าย, label ใช้ `<p>`/`<span>` + `aria-label` บน `<section>`
- **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`** และเป็น **sibling**
  ของ label ไม่ใช่อยู่ในข้อความ
- **ห้าม `href="#"` ห้าม `onclick=`** · back-to-top ใช้ `<a href="#top">`
- **ห้าม `define:vars`** บนหน้าที่ index ได้ · feed ต้อง server-render แถวแรก
- **`isActivePath()` จาก `../lib/nav`** เท่านั้น ห้ามเขียน isActive เอง
- **`alt` ต้องบรรยายรูปจริง** ไม่ใช่ตัวนับ
- **`color: ${BRAND_TEXT}` บน `<html>` ห้ามหาย** — `verify-build` ตรวจให้
- เมนู navbar: `หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · <ที่เหลือ>`
  ทุกรายการมีไอคอน และประกาศ `links` ชุดเดียวใช้ทั้ง desktop + mobile
- **ไม่มี `/ตรวจหวย` `/แนวทาง` ในเมนูและ footer** — สองหน้านั้นจอดใน
  `src/pages-disabled/` และ GT66B ไม่ใช่เว็บหวย ลิงก์ค้าง = build แดง
- **ไม่มี `/ทางเข้า` ในเมนู** (cta toggle เปิดอยู่ `/login` `/register` เป็นหน้าจริง)
  แต่ footer ยังลิงก์ได้ — route มีจริง
- **`<address>` จาก `BRAND_ADDRESS`** ต้องอยู่ใน footer ที่ active (พอร์ตมาจาก
  `FooterStyle2`) และต้องมีชื่อแบรนด์ปัจจุบัน + อีเมลที่ host ของ `site:`
- **ห้ามเขียน `workspec.md`**
