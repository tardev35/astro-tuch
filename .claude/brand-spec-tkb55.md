## §6 Title / Description

**หน้าแรก** — ใช้บรรทัด Title/Description ของบรีฟตรงตัว (content.txt บรรทัด 1-2)
**ห้ามเติมให้ครบ 150 ตัวอักษร** (`verify-build` ยกเว้นเพดานล่างให้หน้าแรกไว้แล้ว):

```
title       = `${BRAND_NAME} เว็บคาสิโนไทย เซิร์ฟต่างประเทศ ยอดเข้าบริษัทโดยตรง`
description = `${BRAND_NAME} เว็บคาสิโนไทย เข้าเล่นปลอดภัย ด้วยเซิร์ฟต่างประเทศ บาคาร่า ไฮโล บอล สล็อต ครบ ฝากถอนทุกธนาคาร ยอดเข้าบริษัทโดยตรง`
```

ค่านี้ถูกตั้งเป็น default ใน `MainLayout.astro` แล้ว และ `index.astro` ส่งสตริง
**เดียวกันเป๊ะ** กลับเข้าไป (เป็น no-op ไม่ใช่แหล่งความจริงที่สอง)

**หน้าย่อย** — บรีฟรอบนี้**ไม่มี**ส่วน `SUB-PAGES (Title & Meta Description)`
แต่ละ agent จึงต้องเขียนเอง **นับเป็น "ตัวอักษร" ไม่ใช่ไบต์** และคุมให้อยู่ที่
**150–160 ตัวอักษร** หนึ่งประโยคที่บอกว่าหน้านี้มีไว้ทำอะไร แล้วหยุด
(รอบก่อนๆ หน้าย่อยยาวเกินทุกครั้งเพราะเติมอนุประโยคไปเรื่อยๆ)

## §7 คลังคำของรอบนี้ (ใช้ได้เฉพาะคำที่บรีฟพูดเอง)

เป็นแบรนด์ **คาสิโน + กีฬา** คำเกมที่มีได้มีสี่คำเท่านั้น:
**บาคาร่า · ไฮโล · บอล (บอลออนไลน์/ฟุตบอล) · สล็อต**

คำอื่นที่ใช้ได้ ทุกคำมาจาก `content.txt`:
เว็บคาสิโนไทย · เซิร์ฟเวอร์ต่างประเทศ · ยอดเข้าบริษัทโดยตรง · ฝากถอนทุกธนาคาร ·
แพลตฟอร์มเดียว · บัญชีเดียว · หมวดเกม · เกมไพ่ · ลูกเต๋า · เกมวงล้อทั่วไป ·
ฟรีสปิน · ฟีเจอร์โบนัส · รายการแข่งขัน · อัตราต่อรอง · ตารางจ่าย · กติกา ·
ยอดเดิมพันขั้นต่ำ · วิธีตัดสินผล · ตรวจสอบเครดิต · 24 ชั่วโมง ·
โบนัสคืนยอดเสีย 0.3% · เข้ายูสทุกวัน · รอบประจำวัน · เวลาตัดยอด · ยอดที่เข้าเกณฑ์ ·
แนะนำเพื่อน · โบนัส 0.8% · ไม่จำกัด · ลิงก์แนะนำ · ชื่อนิติบุคคล ·
ชื่อบัญชีรับเงิน · หลักฐานธุรกรรม · แอดมิน · รหัสผ่าน · PIN · OTP ·
ชื่อคู่แข่งขัน · หมายเลขรายการ

**ตัวเลขที่อ้างได้มีสามตัวเท่านั้น: `0.3%` · `0.8%` · `24 ชั่วโมง`**

**ห้ามอ้าง** (บรีฟไม่ได้ระบุ): เลขใบอนุญาต · ชื่อหน่วยงานกำกับ · ชื่อนิติบุคคลจริง ·
ชื่อค่ายเกม · ชื่อธนาคาร · ค่า RTP · ยอดฝากขั้นต่ำเป็นตัวเลข · จำนวนสมาชิก ·
ปีที่ก่อตั้ง · ที่ตั้งเซิร์ฟเวอร์ที่เจาะจงกว่า "ต่างประเทศ"
**ห้ามมีคำเกี่ยวกับหวยที่ไหนเลย** — ไม่ใช่เว็บหวย

## §8 กฎที่ build บังคับ (พลาดแล้วแดง ไม่ใช่แค่เสียฟอร์ม)

1. `<h1>` ได้หน้าละ **หนึ่งตัว** เท่านั้น
2. `alt` ต้อง **บรรยายรูป** ไม่ใช่ `"bank"` / `"ภาพที่ 3"` — รูปตกแต่งใช้ `alt=""` + `aria-hidden`
3. emoji ตกแต่งต้องอยู่ใน `<span aria-hidden="true">` **แยกจาก label เสมอ** ห้ามฝังในข้อความ
4. **ห้าม** `href="#"` และ **ห้าม** `onclick=` — ปุ่มกลับขึ้นบนใช้ `href="#top"`
5. **ห้าม** `define:vars` / `<script>` ที่ไม่มี attribute บนหน้าที่ index ได้
6. FAQ ต้องเป็น `<details>`/`<summary>` ห้ามกลับไปใช้ปุ่ม + `max-height`
7. widget ที่หัวข้อเป็น `<p>` ต้องมี `aria-label` บน `<section>`
8. JSON-LD มาจาก `pageGraph()` เท่านั้น — **ห้าม** `Review` `AggregateRating` `sameAs`
   `address`/`PostalAddress` `email` ใน structured data
9. `<address>` ทุกตัวที่ render ต้องมี `BRAND_NAME` ปัจจุบัน และอีเมลต้องอยู่ที่ host ของ `site:`
10. AVIF ต้องไม่ใหญ่กว่า WebP คู่ของมัน — ปล่อย `quality={80}` ไว้เฉยๆ
    (`tools/avif-quality-service.mjs` ปรับให้เอง) **ห้าม**จูนรายฟอร์แมตเอง
11. **ห้ามเหลือ HTML comment `<!-- -->`** ในไฟล์ที่ render — Astro ส่งออกไป dist ตรงๆ
12. `color: ${BRAND_TEXT}` บน `<html>` ใน `MainLayout` **ห้ามลบ**
13. **ห้าม** `mx-auto` / `max-w-*` บน `<p>` ในหน้า — การ์ดคุมความกว้างเองแล้ว
14. **ห้าม**เขียน `isActive` เอง ใช้ `isActivePath` จาก `../lib/nav`
15. **ห้าม**เพิ่ม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`
16. อย่าแก้ `src/styles/_sources.generated.css` — build เขียนให้เอง
