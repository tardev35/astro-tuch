### อ่านจากงานศิลป์จริง (เปิดดูด้วย Read ทั้ง 4 ไฟล์ + `palette.json`)

- **logo.webp** — คำว่า **ขวัญใจ** เป็นตัวอักษรไทยหนาสามมิติ **ผิวทองขัดเงา** ตัดขอบแดงเข้ม
  ต่อด้วยเลข **168** ทองสามมิติ ทั้งหมดวางบนโบว์/ริบบิ้นทองโค้ง ด้านหลังเป็นหญิงสาว
  ผมดำเกล้ามวยสูงประดับ **ปิ่นทองห้อยระย้า** และ **ดอกไม้สีขาว** ทำมือเป็นรูปหัวใจเล็ก
  สวมชุดไทยสีแดงปักทอง ล้อมด้วย **เหรียญจีนทองรูสี่เหลี่ยม** กองเหรียญทอง และ
  **หัวใจสีแดงสองดวง**
- **banner1.png** — ฉากพื้นดำ มีหญิงสาวสองคนขนาบซ้าย-ขวา ผมยาวสีดำประดับปิ่นทองและ
  **ดอกลิลลี่ขาว** สวมชุดไทย-จีนสีแดงและครีมปักทอง เครื่องประดับทองเต็มตัว
  มีเหรียญจีนทองร่วงทั่วภาพ ผ้าซาตินแดง และดอกไม้ทอง กลางภาพเป็นโลโก้ ใต้ลงมาเป็น

  **เข้าเล่น ฝากถอน ติดต่อ รับโปร ครบในเว็บเดียว** โดยคำว่า "รับโปร" เป็นทอง

- **slide2.png** (600×600) — โปสเตอร์ **โปรโมชั่น คืนยอดเสีย 0.3%**

  (`#fccab5`, `#f2bba5`, `#ebb294`, `#e4ab94`) ส่วน dominant คือ **ดำสนิท** (`#010101`)

## §8 กติกาที่ `tools/verify-build.mjs` บังคับ (build แดงถ้าผิด)

- `<h1>` ได้หน้าละหนึ่งอันเท่านั้น — chrome (navbar/footer/ticker/feed/การ์ด) **ห้ามใช้แท็กหัวข้อทุกระดับ** ให้ใช้ `<p>`/`<span>` + `aria-label` บน `<section>`
- `alt` ต้องบรรยายภาพจริง · emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และเป็น **พี่น้อง** ของ label ไม่ใช่อยู่ในข้อความ
- ห้าม `href="#"` · ห้าม `onclick=` · ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
- ห้าม `define:vars` / `<script>` ที่ไม่มี attribute บนหน้าที่ index
- JSON-LD มาจาก `pageGraph()` เท่านั้น · ห้ามพิมพ์โดเมน · ห้ามต่อ URL ด้วย `+` ·
  ห้ามใส่ `Review` / `AggregateRating` / `sameAs` / `address` / `PostalAddress` / `email`
- meta `description` ห้ามเกิน 200 ตัวอักษร · ที่เขียนเองให้อยู่ **150–160** (นับ **ตัวอักษร** ไม่ใช่ไบต์) · หน้าแรกยกเว้นเพดานล่าง
- `color:` ที่มาจาก `BRAND_TEXT` บน `<html>` ของ `MainLayout` **ห้ามหาย**
- AVIF ต้องไม่ใหญ่กว่า WebP คู่ของมัน (`quality={80}` ปล่อยไว้ อย่าจูนเอง)
- `<address>` ทุกอันที่ render ต้องมี `BRAND_NAME` ปัจจุบัน และอีเมลต้องอยู่บนโฮสต์ของ `site:`
- `href` ต้องชี้ route ที่มีจริง (`/ตรวจหวย`, `/แนวทาง` ไม่มีรอบนี้)

## §9 สิ่งที่ห้ามทำรอบนี้

- **ห้าม deploy · ห้าม `git push` · ห้าม `git commit`** — operator สั่งให้หยุดที่ build + verify
- subagent **ห้ามรัน `npm run build`** — build เดียวอยู่ที่ orchestrator
- ห้ามลบ component ที่ไม่ได้ใช้ · ห้ามแก้ `src/styles/_sources.generated.css` (build เขียนเอง)
- ห้ามแตะ `account_id` · ห้ามลบ `workers_dev = false` / `not_found_handling = "404-page"`
- ห้ามสร้าง `public/robots.txt` (มี route generate ให้แล้ว)
- ห้ามจัดระเบียบ `<head>` ของ `MainLayout` ใหม่ · ห้ามเติม `google-site-verification`
