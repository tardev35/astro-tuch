## §5 คำที่ใช้ได้ / ห้ามใช้

ไม่ทำเทิร์น / ไม่ต้องทำเทิร์น · รวมค่ายดัง · ใช้ทุนเล่นน้อย · เบทต่ำ 1 บาท ·

  ที่ใช้งานอยู่** (ตรวจแล้ว `NavbarStyle5` + `FooterStyle2` ไม่มีลิงก์ มีแต่คอมเมนต์)

  มี `targetUrl` + `CtaRedirect`) จึงอยู่ในเมนู navbar ถัดจาก `โปรโมชั่น` ทันที
  และ **`/ทางเข้า` ถูกถอดออกจากเมนู navbar** (หน้ายัง route อยู่ footer ยังลิงก์ได้)

  ให้ rebrand เนื้อหาเต็ม ไม่ต้อง park
- ไม่มีไฟล์ไหนใน `src/pages/` มี `TODO(rebrand)` เหลืออยู่ (ตรวจแล้ว)
- **`terms.astro` / `privacy.astro` / `404.astro`** เป็นไฟล์ถาวร brand-neutral —
  ทุกคำที่เป็นของแบรนด์มาจาก `BRAND_NAME` และสีมาจาก `ContentBox` + `BRAND_TEXT`
  **ห้ามใส่คลาสสีลงในย่อหน้าของสองหน้านี้** และ **ต้อง render ผ่าน `ContentBox.astro`

## §8 กติกาที่ build บังคับ (ย้ำ — `tools/verify-build.mjs` ทำให้ build แดง)

1. **หนึ่ง `<h1>` ต่อหน้า** · heading ทุกตัวต้องมาจาก prop ที่รับค่าจากบรีฟ
   **chrome (navbar/footer/ticker/ฟีด/การ์ดรีวิว/ป้ายคอลัมน์) ห้ามออกแท็ก heading
   ทุกระดับ** → ใช้ `<p>`/`<span>` + `aria-label` บน `<section>`
2. **ห้ามมี HTML comment (`<!-- -->`)** ในไฟล์ที่ render — Astro ส่งขึ้น production ตรงๆ
   คอมเมนต์อธิบายให้อยู่ใน frontmatter (`//`) เท่านั้น
3. **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`** และเป็น **พี่น้อง**
   ของ label ไม่ใช่อยู่ในข้อความ · **ห้ามใส่ emoji ใน prop ข้อความ** (เช่น `message`
   ของ ticker) เพราะ mark ไม่ได้
4. **ห้าม `href="#"` ห้าม `onclick=`** · ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
5. **`alt` ต้องบรรยายภาพจริง** — ภาพซ้ำเพื่อ seamless loop ใช้ `alt=""` +
   `aria-hidden="true"` บน wrapper
6. **FAQ ใช้ `<details>`/`<summary>`** ห้ามกลับไปใช้ button + max-height
7. **ห้าม `define:vars`** บนหน้า indexable · ห้าม `<script>` ไร้ attribute ·
   ห้าม `Math.random()`/`Date.now()` ใน frontmatter (ใช้ `brandPick`/`brandFlag`)
8. **`isActive` ในทุก navbar ต้องมาจาก `isActivePath` ของ `../lib/nav`**
9. **JSON-LD มาจาก `pageGraph()` เท่านั้น** · ห้ามเพิ่ม `Review`/`AggregateRating`/
   `sameAs`/`address`/`PostalAddress`/`email`
10. **`<html>` ต้องคง `color: ${BRAND_TEXT}` ใน inline style**
11. **ทุก `<address>` ที่ render ต้องมี `BRAND_NAME` ปัจจุบัน** และอีเมลต้องอยู่บน
    host ของ `site:` → ใช้ `BRAND_ADDRESS` เท่านั้น ห้ามพิมพ์มือ
12. **AVIF ต้องไม่ใหญ่กว่า WebP คู่ของมัน** (image service จัดการให้แล้ว —
    ใช้ `quality` ปกติ ห้ามดันขึ้น)
13. **meta description ห้ามเกิน 200 ตัวอักษร** (เป้าหมายจริง 150–160 สำหรับหน้าย่อย)
14. **`wrangler.toml` `name` ต้องตรงกับ `hostname.split(".")[0]` ของ `site:`**
15. **ย่อหน้าในการ์ดเป็น `text-left text-base leading-relaxed`** · หัวข้อจัดกลางได้
    แต่ต้องใส่ `text-center` บนตัว heading ไม่ใช่บนการ์ด/`<section>` ·
    **ห้ามใส่ `mx-auto max-w-*` บน `<p>` ในหน้า**
16. **หนึ่ง slot = หนึ่ง element** · ห้ามใส่ wrapper `<div>` กลับเข้าไปใน ContentBox
    ที่ flatten แล้ว
