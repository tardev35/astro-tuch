### อาร์ตเวิร์กรอบนี้ (อ่านจากไฟล์จริงด้วย Read)
- **โลโก้** — แมวการ์ตูนขนขาวลายส้ม หน้ายิ้มหลับตา ยกอุ้งเท้าขึ้น ใส่ปลอกคอฟ้ามีกระดิ่งทอง
  นั่งคู่กับ **มือถือจอฟ้ามีลูกศรดาวน์โหลดสีน้ำเงิน** และ **ปึกแบงก์สีฟ้า** มี **เหรียญบิตคอยน์ทอง**
  และ **หัวใจสีฟ้า** ลอยรอบ ใต้ลงมาเป็นคำว่า **สบาย** ตัวอักษรไทยหนาสามมิติ **สีทอง**
  ต่อด้วย **เบท168** สามมิติ **สีฟ้าบับเบิล** (ผิวมันวาวแบบลูกโป่ง)
- **banner1** — ฉากพื้นดำ กลางภาพเป็นโลโก้คำว่า **สบายเบท168** ตัวโต (สบาย=ทอง, เบท168=ฟ้า)
  มีมงกุฎทองบนเลข 8 แมวการ์ตูนตัวโตอยู่เหนือตัวอักษร ใต้ลงมาสองแถบคำโปรย
  **เว็บสล็อตทางการ** (ขอบฟ้าเรืองแสง มีดาวทองสองข้าง) และ **ผู้ให้บริการฐานเกมหลัก เว็บแท้อันดับ1**
  (มีโล่ติ๊กถูกสีฟ้าและมงกุฎทอง) ฝั่งขวาเป็น **หญิงสาวผมบลอนด์เงิน ผูกโบว์ซาตินฟ้า**
  ขยิบตา เป่าจูบ สวมชุดลูกไม้ขาว-ฟ้า ข้างๆ มี **มือถือจอขาวขึ้นติ๊กถูกในวงกลมฟ้าพร้อมคำว่า ถอนสำเร็จ**
  มุมล่างซ้ายเป็น **กล่องของขวัญผูกโบว์ฟ้า** เหรียญบิตคอยน์ทอง และ **หัวใจฟ้า** กระจายทั่วภาพ
  มีเส้นแสงฟ้าโค้งเป็นฉากหลัง
- **slide1.png** — ป้าย **โปรโมชั่น** (ตัวอักษรทอง) + **แนะนำเพื่อน** + **0.8%** (ฟ้า)
- **slide2.png** — ป้าย **โปรโมชั่น** (ตัวอักษรทอง) + **คืนยอดเสีย** + **0.3%** (ฟ้า)
- `bg.json` = `{"mode":"color","color":"#000000"}` → **พื้นเพจดำสนิท**

**ไม่มีในรูปรอบนี้:** แมวกวักจีน · เหรียญจีนรูสี่เหลี่ยม · ทองแท่งจีน · ธงสิงคโปร์ ·
หญิงสาวชุดไทยแดง · ริบบิ้นซาตินชมพู · ปึกแบงก์ชมพู · ดอกซากุระชมพู · ไพ่/ชิปคาสิโน ·
มังกรจีน 龍 · มาสคอตโจร · ปีกเหยี่ยว · เป็ด · หัวเสือ · โปสเตอร์หวย

## §7 สถานะหน้าเว็บรอบนี้

เว็บสล็อต → **หน้าหวยต้องปิด**: `ตรวจหวย.astro` / `แนวทาง.astro` อยู่ใน

**ต้องไม่มีลิงก์ `/ตรวจหวย` หรือ `/แนวทาง`** (verify-build จะแดง)

cta toggle **เปิดอยู่** → `/login` `/register` เป็นหน้าปุ่มที่ index ได้จริง
→ เมนู navbar มี `สมัครสมาชิก` + `เข้าสู่ระบบ` ต่อจาก `โปรโมชั่น` ทันที

ลำดับเมนู: `หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · ทดลองเล่น · เกี่ยวกับเรา · ติดต่อเรา`

## §8 กฎที่ต้องถือทุกไฟล์

1. **หัวข้อมาจากบรีฟเท่านั้น** — chrome (navbar/footer/ticker/feed/การ์ดรีวิว/ป้ายกำกับ)
   ห้ามใช้ `<h1>`–`<h6>` ทุกระดับ ใช้ `<p>`/`<span>` คลาสเดิม + `aria-label` ที่ `<section>`
2. **ห้ามมี HTML comment `<!-- -->`** ในไฟล์ที่ render (Astro ส่งออกตรงๆ) — คอมเมนต์ไว้ใน frontmatter
3. ย่อหน้า = `text-left text-base leading-relaxed` + สีจากการ์ด · ห้าม `mx-auto` / `max-w-*` ที่ย่อหน้า
4. หนึ่ง slot = **หนึ่ง element**
5. การ์ดที่ flatten แล้ว **ห้ามใส่ wrapper `<div>` กลับ** (ใช้ `isolate` + `-z-10` บนชั้นตกแต่ง)
6. emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` · ห้าม emoji นำหน้า message ของ ticker
7. ห้าม `href="#"` · ห้าม `onclick=` · ปุ่มกลับขึ้นบนใช้ `<a href="#top">`
8. `alt` ต้องบรรยายรูปจริง (เปิดอ่านรูปก่อนเขียน) ห้ามเป็น `"bank"` / `"ภาพที่ 3"`
9. FAQ = `<details>`/`<summary>` เท่านั้น ห้าม script accordion
10. ห้าม `define:vars` บนหน้าที่ index ได้ · ห้าม render feed ว่างแล้วเติมด้วย JS
11. navbar ใช้ `isActivePath` จาก `../lib/nav` ห้ามเขียน `isActive` เอง
12. JSON-LD มาจาก `pageGraph()` เท่านั้น · ห้ามพิมพ์โดเมน · ห้ามต่อ URL ด้วย `+` ·
    ห้าม `Review` / `AggregateRating` / `sameAs` / `address` / `email`
13. ห้ามใส่ `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`
14. ที่อยู่/อีเมลมาจาก `BRAND_ADDRESS` เท่านั้น ห้ามพิมพ์เอง · footer ต้อง render `<address>`
15. `description` ที่ **เขียนเอง** = 150–160 ตัวอักษร (นับตัวอักษร ไม่ใช่ไบต์) ·
    ของหน้าแรกใช้บรีฟตรงตัว ห้ามเติม
16. `/contact-us` `/ทางเข้า` `/promotion` = **`h1×1 h2×0 h3×0`** (หน้าปุ่ม/หน้ารูป ไม่ใช่บทความ)
17. **ห้ามรัน `npm run build`** — orchestrator รันครั้งเดียวใน Phase 5
18. **ห้ามลบ component variant ที่ไม่ได้ใช้**
