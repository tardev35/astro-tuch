## §8 กฎที่ยังบังคับอยู่ทุกข้อ (ย่อ — รายละเอียดเต็มอยู่ใน SKILL.md)

- **ห้ามลบ component variant ที่ไม่ได้ใช้** — เป็น inventory ของแบรนด์ถัดไป
- **chrome ห้ามออกแท็ก heading ทุกระดับ** — ticker / ฟีดถอนเงิน / การ์ดรีวิว /
  ป้ายคอลัมน์ / navbar / footer ใช้ `<p>`/`<span>` + `aria-label` บน `<section>`
- **ห้ามเหลือคอมเมนต์ HTML `<!-- -->`** ในไฟล์ที่ render จริง (Astro ส่งขึ้น production ตรงๆ)
  — ตอน retheme ให้กวาดออกในพาสเดียวกัน
- **ห้ามเขียน `isActive` เอง** ใน navbar — ใช้ `isActivePath` จาก `../lib/nav`
- **ห้าม `define:vars`** · ห้าม render ฟีดเป็นคอนเทนเนอร์เปล่า · ห้าม `Math.random()` ใน frontmatter
- **ห้าม `href="#"` · ห้าม `onclick=`** · อีโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`
- **`alt` ต้องบรรยายภาพจริง** (เปิดรูปอ่านก่อนเขียน) ไม่ใช่ `"bank"` / `"ภาพที่ 3"`
- **JSON-LD มาจาก `pageGraph()` เท่านั้น** — ห้ามพิมพ์โดเมน ห้ามต่อ URL ด้วย `+`
  ห้ามเพิ่ม `Review` / `AggregateRating` / `sameAs` / `address` / `email`
- **ย่อหน้าในการ์ด: `text-left text-base leading-relaxed <สี>`** ไม่มี `text-sm`/`text-lg`
  และ **ห้ามใส่ `mx-auto max-w-4xl` บน `<p>` ในหน้า** (การ์ดคุมความกว้างเองแล้ว)
- **ห้ามเพิ่ม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`**
- `<strong>` ต้องคร่อม "ก้อนที่คั่นด้วยช่องว่าง" ทั้งก้อน (ภาษาไทยไม่มีช่องว่างระหว่างคำ)
- **หน้าปุ่ม `/contact-us` `/ทางเข้า` `/login` `/register` และหน้าภาพ `/promotion`:
  `h1 ×1 · h2 ×0 · h3 ×0`** ห้ามเขียนบทความ/หัวข้อย่อยกลับเข้าไป
  `/promotion` มีย่อหน้าเกริ่นได้ **หนึ่งย่อหน้า ~4 บรรทัด** เท่านั้น
- **ห้ามรัน `npm run build`** — build รอบเดียวอยู่ที่ orchestrator ใน Phase 5
