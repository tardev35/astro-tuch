**ห้ามอ้าง:** เลขใบอนุญาต หน่วยกำกับ ชื่อนิติบุคคล ชื่อธนาคารเจาะจง ตัวเลข RTP ยอดฝากขั้นต่ำ จำนวนสมาชิก ปีก่อตั้ง
ตัวเลขที่มีได้มีแค่ของบรีฟเอง: `0.8%` `0.3%` `24ชม.`

**บรีฟรอบนี้ hedge หนักมาก** (`ควรตรวจสอบ…` `แม้จะระบุว่ารับได้ไม่อั้น แต่ควรยืนยัน…`
`เครดิตคืนยอดเสียไม่ได้หมายความว่าจะได้รับเงินคืนจากทุกรายการหรือรับประกันผลตอบแทน`)
— **ประโยค hedge ทุกประโยคต้องขึ้นเว็บครบ** เป็นเนื้อหาของบรีฟ ไม่ใช่ filler ให้ตัดทิ้ง

## §8 กฎที่ build บังคับ (verify-build.mjs จะแดงถ้าพลาด)

- หนึ่ง `<h1>` ต่อหน้า · `alt` ต้องบรรยายรูปจริง · อีโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`
- ห้าม `href="#"` ห้าม `onclick=` ห้าม `define:vars` / `<script>` ไร้ attribute บนหน้า indexable
- FAQ ต้องเป็น `<details>`/`<summary>` ห้ามกลับไปใช้ปุ่ม + `max-height`
- JSON-LD มาจาก `pageGraph()` เท่านั้น — ห้ามพิมพ์โดเมน ห้ามต่อ URL ด้วย `+`
  ห้ามใส่ `Review` `AggregateRating` `sameAs` `address`/`PostalAddress` `email`
- meta description: ที่บรีฟให้มา → ใช้ verbatim · ที่เขียนเอง → **150–160 ตัวอักษร** (นับ "ตัวอักษร" ไม่ใช่ไบต์)
- `<html>` ต้องคง inline `color: {BRAND_TEXT}` ไว้ · `?v=${iconVersion}` บนลิงก์ไอคอนต้องอยู่ครบ
- AVIF ต้องไม่ใหญ่กว่า WebP คู่ตัวเอง · ห้ามมีรูปที่ import แล้วไม่มีหน้าไหน render
- `<address>` ทุกจุดต้องมี `BRAND_NAME` ปัจจุบัน และอีเมลต้องอยู่บน host ของ `site:`
- ห้ามเหลือ HTML comment `<!-- -->` ในไฟล์ที่ render (Astro ส่งไปถึง output)
- ห้ามใส่ `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`
- navbar ใช้ `isActivePath()` จาก `src/lib/nav` เท่านั้น ห้ามเขียน `isActive` เอง
- พฤติกรรมอยู่ใน `src/lib/` (`nav.ts` `liveCounter.ts` `winnersFeed.ts`) — retheme markup/class ได้ **ห้ามย้าย logic กลับเข้า component**

## §9 house style ที่ต้องคงไว้

- ย่อหน้าในการ์ด: `text-left text-base leading-relaxed <สีเนื้อความ>` บน element ที่ถือ slot
  หัวข้ออาจ `text-center` ได้ แต่ต้องใส่ที่ตัวหัวข้อเอง **ห้ามใส่บนการ์ด/`<section>`**
- **ห้ามใส่ `mx-auto max-w-*` ให้ `<p>` ในหน้าเพจ** — การ์ดคุมความกว้างเองแล้ว
- single-slot variants flatten แล้ว (`isolate` บนการ์ด + `-z-10` บนเลเยอร์ตกแต่ง) — **ห้ามเติม wrapper `<div>` กลับ**
- หนึ่ง slot = หนึ่ง element เสมอ
- เมนู navbar: ทุกรายการต้องมีไอคอน ใน `links` array ตัวเดียว (desktop+mobile ใช้ร่วมกัน)
  ไอคอนเป็น `<span aria-hidden="true">` ที่เป็น **พี่น้องของ label ไม่ใช่อยู่ในข้อความ**
  ลำดับ: `หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · <ที่เหลือ>`
  (`ทางเข้า` ออกจากเมนูโดยตั้งใจ เพราะ cta toggle เปิดอยู่ — **ห้ามเติมกลับ**)
- footer ที่ใช้งานอยู่ต้องมีบล็อก `<address>` จาก `BRAND_ADDRESS` **วางทับแบบ verbatim ห้าม theme ห้ามใส่ hex**
