## §9 กฎที่ build บังคับ (`tools/verify-build.mjs` — แดงถ้าผิด)

- `<h1>` ได้หน้าละ **หนึ่งอัน** เท่านั้น
- `alt` ต้องบรรยายรูปจริง · emoji ตกแต่งต้องอยู่ใน `aria-hidden="true"` ที่เป็น
  **พี่น้อง** ของ label ไม่ใช่อยู่ในข้อความ
- **ห้าม `href="#"` ห้าม `onclick=`** · back-to-top ใช้ `<a href="#top">`
- **ห้าม `define:vars`** / `<script>` ที่ไม่มี attribute บนหน้าที่ index ได้
- FAQ ต้องเป็น `<details>`/`<summary>` **ห้ามใส่ `<script>` กลับเข้าไป**
- วิดเจ็ตที่หัวข้อเป็น `<p>` ต้องมี `aria-label` บน `<section>`
  **ห้ามเลื่อน `<p>` ขึ้นเป็น `<h2>` เพื่อ "แก้"**
- `href` ต้องชี้ route ที่มีจริง · canonical ต้องตรง host · ห้ามโดเมนแบรนด์เก่า
- `meta description` ≤ 200 ตัวอักษร (เป้า **150–160**; หน้าแรกยกเว้นเพดานล่าง)
- `<address>` ทุกอันต้องมี `BRAND_NAME` ปัจจุบัน และอีเมลต้องอยู่โฮสต์ของ `site:`
- AVIF ต้องไม่ใหญ่กว่า WebP พี่น้องของมัน
- ห้ามมีรูปที่ import แล้วไม่มีเวอร์ชันไหนถูก render
- `color:` จาก `BRAND_TEXT` บน `<html>` ต้องอยู่
- JSON-LD ต้อง parse ได้ · **ห้าม `Review` / `AggregateRating` / `sameAs` /
  `address` / `PostalAddress` / `email` ใน JSON-LD**
- **ห้ามคอมเมนต์ HTML (`<!-- -->`)** ในไฟล์ที่ render จริง — Astro ส่งขึ้น production
