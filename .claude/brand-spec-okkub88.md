## §9 — กฎที่ทุก agent ต้องถือ

1. **ห้ามรัน `npm run build`** — บิลด์เดียวของรอบนี้อยู่ที่ orchestrator (Phase 5)
2. **ห้ามลบ component variant ที่ไม่ได้ใช้** — เป็นอินเวนทอรีของแบรนด์ถัดไป
3. **ห้าม re-extract docx · ห้ามเลือก variant เอง** — อ่านไฟล์นี้
4. **ทุกหน้าต้องเปลี่ยน `import Announcement from "../components/Announcement.astro"`
   → `"../components/Announcement3.astro"`** (ตัวไฟล์ `Announcement3.astro`
   เป็นของ P1 — agent แก้แค่บรรทัด import ในหน้าของตัวเอง)
5. **ห้ามมี `<!-- ... -->` ในไฟล์ที่ render** (Astro ส่ง HTML comment ขึ้น dist)
   คอมเมนต์ใน frontmatter (`//`) ปลอดภัย
6. **โครมห้ามถือ heading** — ป้าย UI ทุกชิ้นเป็น `<p>`/`<span>` + `aria-label`
   บน container ห้ามเป็น `<h1>`–`<h6>`
7. **emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`** ของตัวเอง
   (ห้ามอยู่ในสตริงเดียวกับข้อความ) และ **ห้ามขึ้นต้นข้อความ `message` ของ ticker**
8. **ห้าม `href="#"` · ห้าม `onclick=`** (back-to-top ใช้ `href="#top"`)
9. **ห้าม `define:vars`** และ **ห้าม `<script>` ที่ไม่มี attribute** บนหน้าที่ index ได้
10. **`alt` ต้องบรรยายรูป** — ของโปสเตอร์โปรโมชั่นคือข้อความที่พิมพ์อยู่บนภาพจริง
11. **ห้ามเขียน JSON-LD เอง** — เรียก `pageGraph()` และ **ห้ามใส่ `Review` /
    `AggregateRating` / `sameAs` / `address` / `PostalAddress` / `email`**
12. **ห้ามแก้ `targetUrl`** ใน `login.astro` / `register.astro` / `Navfoot.astro`
    (= `https://yoalink.com/hx8w` uploader ตั้งให้แล้ว) และ **ห้ามแก้ redirect
    `/line`** ใน `astro.config.mjs` (= `https://tinyurl.com/linetddy`)
13. **ย่อหน้าในกล่องเนื้อหา: `text-left text-base leading-relaxed`** ห้าม `text-sm`
    ห้าม `mx-auto max-w-4xl` บน `<p>` ในหน้า (การ์ดจำกัดความกว้างให้อยู่แล้ว)
14. **1 slot = 1 element** — ถ้าต้องหลาย block ให้ห่อเองใน `<div>` เดียว
15. **ห้ามเพิ่ม `<div>` wrapper กลับเข้า `ContentBox*`** (ทุกไฟล์ flatten แล้ว
    ใช้ `isolate` + `-z-10` บนชั้นตกแต่ง)
16. **ห้ามเขียน `isActive` เอง** ใน navbar — `import { isActivePath } from "../lib/nav"`
17. **`<Image>`/`<Picture>` ต้องมี `widths` + `sizes` ตามขนาดที่วาดจริง**
18. **รอบนี้เป็นเว็บสล็อต ไม่ใช่เว็บหวย** → `ตรวจหวย.astro` / `แนวทาง.astro`
    อยู่ใน `src/pages-disabled/` **ถูกต้องแล้ว ห้ามย้ายกลับ** และลิงก์ของทั้งสอง
    ต้องไม่มีใน navbar + footer ที่ใช้งานอยู่
19. **`src/pages-disabled/about-us.astro` เป็นสำเนาเก่าที่จอดไว้** ตัวที่ route จริง
    คือ `src/pages/about-us.astro` — **ห้ามแก้ ห้ามลบ ห้ามสลับไฟล์**
