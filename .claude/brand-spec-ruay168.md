## §6 — กฎโครงสร้างที่ทุก agent ต้องถือ

1. **ชื่อแบรนด์ห้ามพิมพ์ตรงๆ** ในหน้า/คอมโพเนนต์ — `import { BRAND_NAME } from "../lib/brandProfile"` แล้ว interpolate ทุกจุด (รวม `alt=`)
2. **ห้ามพิมพ์โดเมนที่ไหนเลย** และ **ห้ามต่อ URL ด้วย `+`** — JSON-LD มาจาก `pageGraph()` ตัวเดียว
3. **chrome ห้ามถือแท็ก heading ทุกระดับ** — ticker / ฟีด / การ์ดรีวิว / ป้ายคอลัมน์ / footer ใช้ `<p>`/`<span>` + `aria-label` บน `<section>`
4. **ห้ามมี HTML comment `<!-- -->`** ในไฟล์ที่ render — Astro ship ลง dist ตรงๆ (คอมเมนต์ JS ใน frontmatter ปลอดภัย ใช้ได้)
5. **ย่อหน้าเนื้อความ**: element ที่ถือ slot ได้ `text-left text-base leading-relaxed` + สีหมึก — **ห้าม `text-sm`/`text-lg`** และ **ห้าม `mx-auto max-w-*` บน `<p>` ในหน้า**
6. **one element per slot** — ถ้าต้องใส่หลายบล็อก (เช่น `<p>` + `<Picture>`) ให้ห่อเป็น `<div>` เดียวเอง
7. **ห้าม `define:vars`** · ห้าม `href="#"` · ห้าม `onclick=` · `alt` ต้องบรรยายภาพจริง · emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`
8. **ห้ามย้าย logic กลับเข้า component** — `isActivePath` จาก `../lib/nav`, ฟีดจาก `../lib/winnersFeed`, ตัวนับจาก `../lib/liveCounter`
9. **ห้ามเติม `<style>` ที่มีแค่ `.font-sans { font-family: var(--font-sans) }`** และ **ห้าม hardcode `font-family` / เติม `<link>` Google Fonts**
10. **ห้ามเพิ่ม** `Review` · `AggregateRating` · `sameAs` · `address`/`PostalAddress` · `email:` เข้า JSON-LD
11. **ห้ามลบ variant ที่ไม่ได้ใช้** ใน `src/components/`
12. **ห้ามรัน `npm run build`** — orchestrator build ครั้งเดียวใน Phase 5
13. **ห้าม `git commit` / `git push` / deploy** — รอบนี้หยุดที่ build + verify ตามคำสั่ง operator
14. `description` ที่ **เขียนเอง** ต้องยาว **150–160 ตัวอักษร** (นับ *ตัวอักษร* ไม่ใช่ไบต์ — ไทย 3 ไบต์/ตัว)

## §7 — เมนู navbar (เรียงตามกฎ playbook)

cta toggle **เปิดอยู่** (`login.astro` / `register.astro` เป็นหน้าปุ่มจริงใน `src/pages/`)
→ **`ทางเข้า` ไม่อยู่ในเมนู** (แต่หน้ายังอยู่และยัง index)

```
หน้าแรก · โปรโมชั่น · สมัครสมาชิก · เข้าสู่ระบบ · ตรวจหวย · แนวทาง · ทดลองเล่น · เกี่ยวกับเรา · ติดต่อเรา
```
- `สมัครสมาชิก` (`/register`) และ `เข้าสู่ระบบ` (`/login`) ต้องอยู่ **ถัดจาก `โปรโมชั่น` ทันที**
- **ทุกรายการต้องมีไอคอน** — ใส่ใน `links` array ข้าง `name`/`path` แล้ว render เป็น
  `<span aria-hidden="true">` ที่เป็น **พี่น้องของ label ไม่ใช่อยู่ในข้อความ**
- ไอคอนต้องเข้าธีมหวย (🎯 🎫 🏆 📊 ฯลฯ) ไม่ใช่ไอคอนสล็อต
- ถ้า variant ประกาศเมนูสองชุด (desktop + mobile) ให้ **รวมเป็น `links` const เดียว**
