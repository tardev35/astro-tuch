## §1 อาร์ตเวิร์ก (เปิดดูไฟล์จริงแล้วทุกไฟล์)

**โลโก้ `logo.webp`** — พื้นโปร่งใส: **หัวมังกรจีนสีทองสามมิติหันซ้าย อ้าปาก มีเขาและหนวดเป็นเส้นทอง**

**แบนเนอร์ `banner1.png` (แนวนอน) / `banner1-mobile.png` (จัตุรัส)** —
**ห้องนิรภัยทองคำ**: ฉากหลังเป็น **ประตูเซฟวงกลมทองเหลืองขนาดใหญ่** และ **ชั้นวางทองคำแท่ง**

## §6 กฎที่บังคับใช้ทั้งทุก agent

1. **ห้ามพิมพ์ชื่อแบรนด์ตรงๆ** ใช้ `${BRAND_NAME}` จาก `../lib/brandProfile` เสมอ (รวมใน `alt=`)
2. **ห้ามพิมพ์โดเมน** และ **ห้ามประกอบ URL ด้วย `+`** — JSON-LD มาจาก `pageGraph()` เท่านั้น
3. **ห้ามใส่ `<!-- HTML comment -->`** ในไฟล์ที่ render — Astro ส่งขึ้น production ตรงๆ
   คอมเมนต์อธิบายให้อยู่ใน frontmatter (`//`) เท่านั้น **และตอน retheme ให้ลบคอมเมนต์ HTML
   เดิมที่ค้างอยู่ในไฟล์นั้นออกด้วย**
4. **ห้ามลบไฟล์ component ใดๆ** — ที่ไม่ได้ใช้คือ inventory
5. **`npm run build` เป็นของ orchestrator เท่านั้น — subagent ห้ามรัน**
6. **เลข/คำ ต้องมาจาก §5 เท่านั้น**
7. `description` ที่เขียนเอง = **150–160 ตัวอักษร** (นับ "ตัวอักษร" ไม่ใช่ไบต์)
   — ยกเว้นหน้าแรกที่ใช้บรรทัด `Description` ของบรีฟตรงตัว ไม่ต้องเติมให้ครบ 150
8. **อีโมจิตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"`** และเป็น **พี่น้อง** ของข้อความ
   ไม่ใช่อยู่ในข้อความ · **ห้าม `href="#"` · ห้าม `onclick=` · ห้าม `<script>` ไม่มี attribute**
9. **`alt` ต้องบรรยายรูป** ไม่ใช่ชื่อไฟล์ ไม่ใช่ตัวนับ
10. **ห้ามเขียน `isActive` เอง** ใน navbar — ใช้ `isActivePath` จาก `../lib/nav`
11. ย่อหน้าในกล่อง = `text-left text-base leading-relaxed` + สีหมึก **ห้าม `mx-auto` / `max-w-*`
    บน `<p>` ในหน้า** · หัวข้ออาจ `text-center` ได้แต่ต้องใส่ที่ตัวหัวข้อ ไม่ใช่ที่ card/section
12. **ห้ามเติม `Review` / `AggregateRating` / `sameAs` / `address` / `PostalAddress` / `email`
    ลง JSON-LD**
13. 1 slot = **1 element** เสมอ
