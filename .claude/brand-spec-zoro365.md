## §1 ทิศของธีมรอบนี้ — 🚨 **กลับทิศจากรอบก่อน: รอบนี้มืดทั้งเว็บ**

`src/assets/bg.json` ของดรอปนี้ = `{"mode":"color","color":"#002908"}` = **เขียวป่าจมเกือบดำ**
⚠️⚠️ **รอบก่อน (TEVA69) เป็น `f0ffeb` = ขาวอมมิ้นต์จาง (ธีมสว่าง) — รอบนี้กลับทิศ 180°**
→ **ทั้งเนื้อหาและโครมเป็นผิวเข้ม** การ์ดเนื้อหาเป็นเขียวป่าเข้มบนพื้นเพจเขียวจม
→ **ตัวอักษรทั้งเว็บเป็นหมึกสว่าง** ไม่ใช่หมึกเข้มเหมือนรอบก่อน
→ **ห้ามคงการ์ดสีขาว `#ffffff` ของรอบก่อนไว้แม้แต่ใบเดียว** ขาวเป็นพื้นถมใหญ่
รอบนี้ = จอสว่างแปลบกลางหน้าเข้ม
→ บล็อก `<address>` ใน footer **paste verbatim ตาม SKILL.md ได้ตามปกติ**
(`border-white/15` + `bg-black/20` + ตัวอักษร inherit) เพราะ footer เป็นผิวเข้ม

bg.json คือ **แหล่งเดียว** ของพื้นเพจ — ห้ามอนุมานจากรูป (แบนเนอร์รอบนี้เป็นฉากห้อง
**สว่าง** ซึ่ง **ไม่ใช่** ที่มาของพื้นเพจ)

`NavbarStyle10` ขาออกเป็น **สองชั้น — แถบข้อมูลบางเต็มความกว้าง + แถบเมนูทรงแคปซูล
`rounded-[20px]` สูง 75px ลอยไม่ชิดขอบจอ** ส่วน **`NavbarCyber` เป็นแถบแนวนอน sticky
สูง 80px เต็มความกว้างที่ตัดมุมล่างซ้ายด้วย `clip-path: polygon(...)`** — มุมตัดเฉียง
อ่านเป็น "รอยดาบ" ซึ่งตรงกับภาษาภาพคาทานะ/พู่กันหมึกของรอบนี้พอดี ·
`FooterStyle2` ขาออกเป็น **แผ่นแบน ขอบบนเส้นหนา 3px ไม่มีมุมมน กริด 4 คอลัมน์เท่ากัน**
ส่วน **`FooterCyber` เป็นแผ่น `rounded-t-[3rem]` มีออราเบลอคร่อมสองขอบ กริด 12 คอลัมน์
แบ่ง 5/3/4** และ **ไม่ import `BankStrip`** ซึ่งเป็นเงื่อนไขบังคับรอบนี้ (ดู §5)

⚠️ **`NavbarCyber` + `FooterCyber` ปัจจุบันเป็นสีม่วง/แมเจนต้าของ ZANE96**
(`bb6dff` `190b3d` `f3e8ff` `c2178b` ฯลฯ) — ต้อง retheme ทั้งไฟล์ก่อนต่อเข้าระบบ

## §9 กฎที่ build บังคับ (verify-build.mjs จะแดง)

- `alt` ต้องบรรยายรูป · `<h1>` ได้หน้าละหนึ่งอันเท่านั้น · ห้าม `href="#"` ·
  ห้าม `onclick=` · ห้าม `define:vars` / `<script>` ไม่มี attribute บนหน้าที่ indexable
- emoji ตกแต่งต้องอยู่ใน element ที่มี `aria-hidden="true"` และเป็น **พี่น้อง**
  ของ label ไม่ใช่อยู่ในข้อความ
- FAQ ต้องเป็น `<details>`/`<summary>` ห้ามกลับไปเป็น button + max-height
- widget ที่หัวข้อเป็น `<p>` ต้องมี `aria-label` บน `<section>`
- JSON-LD ต้องมาจาก `pageGraph()` เท่านั้น · **ห้าม `Review` / `AggregateRating` /
  `sameAs` / `address` / `PostalAddress` / `email`**
- AVIF ต้องไม่ใหญ่กว่า WebP คู่ของตัวเอง · `<html>` ต้องมี `color:` จาก `BRAND_TEXT`
- `<address>` ที่ render ต้องมี `BRAND_NAME` ปัจจุบัน และอีเมลต้องอยู่บนโฮสต์ของ `site:`
- `meta description` ห้ามเกิน 200 ตัวอักษร
- ห้ามมี HTML comment (`<!-- -->`) ใน component ที่ render จริง — Astro ส่งขึ้น dist ตรงๆ
- `isActive` ต้องมาจาก `isActivePath` ใน `src/lib/nav` **ห้ามเขียนเอง**
