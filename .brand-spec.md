## §7 Rules that fail the build if you break them

These are enforced by `tools/verify-build.mjs`, not by review:

1. **Only docx content may produce a heading.** Chrome (ticker, winners feed,
   card labels, column headers, carousel captions, login box) renders its label
   as `<p>`/`<span>` + `aria-label` on the section. A second `<h1>` on any
   indexable page fails the build.
2. **`alt` must describe the picture** — write it from §4, never `"banner"` or a
   counter. Decorative repeats get `alt=""` + `aria-hidden="true"` on the wrapper.
3. **Decorative emoji live in their own `<span aria-hidden="true">`**, never
   inside a text node and never baked into a text prop (the marquee prints its
   message twice).
4. **No `href="#"`, no `onclick=`.** Back-to-top is `<a href="#top">`.
5. **No `define:vars`, no attribute-less `<script>`** on an indexable page.
6. **No HTML comments (`<!-- -->`)** anywhere that renders — Astro ships them
   verbatim. Strip them from every component you retheme. Notes go in the
   frontmatter (`//`), which IS stripped.
7. **JSON-LD only via `pageGraph()`** from `src/lib/schema.ts`. Never type a
   domain, never build a URL with `+`, never add `Review` / `AggregateRating` /
   `sameAs` / `address` / `PostalAddress` / `email`.
8. **`<address>` on a page must name `หวย365`** and any email in it must be at
   `365-lotto.net`. It comes from `BRAND_ADDRESS` — never retype the lines.
9. **AVIF must not outweigh its WebP sibling.** The image service already scales
   AVIF quality by 0.65; just pass `quality={80}` and real `widths`/`sizes`.
10. **`isActivePath()` from `src/lib/nav`** — never hand-roll `isActive` in a
    navbar (Thai routes are percent-encoded).
11. Every `href` must point at a route that exists.

## §8 House style

- Body copy inside any content box: `text-left text-base leading-relaxed` + the
  card's colour. No `text-sm`, no `text-lg`, no `mx-auto max-w-4xl` on a `<p>`.
- A heading may be centred, but put `text-center` on the heading/`<header>`,
  never on the card or `<section>` — it inherits into the slot.
- **One element per slot.** Multiple blocks go inside one wrapper `<div>`.
- Single-slot `ContentBox*` files are already flattened (`isolate` on the card,
  `-z-10` on decorative layers, slot as a direct child). **Do not re-add a
  wrapper `<div>`.**
- `<strong>` highlights wrap a whole space-delimited chunk — Thai has no
  inter-word space, so a highlight that starts mid-word lets the formatter break
  the line inside the tag. One highlight colour only: `GOLD_LIGHT #ffeab0`.
- Behaviour lives in `src/lib/` (`nav.ts`, `liveCounter.ts`, `winnersFeed.ts`).
  Retheme markup and classes; never move the logic back inline.
- Don't add a `<style>` block whose only rule is
  `.font-sans { font-family: var(--font-sans) }` — it stamps `data-astro-cid-*`
  on every element for no visual change.
