## §9 — House rules that bite during a rebrand

- **Body copy is `text-left text-base leading-relaxed` + the card's own colour.**
  Headings may centre, but put `text-center` on the heading, never on the card or
  `<section>` — it inherits into the slot.
- **No `mx-auto` / `max-w-*` on a `<p>` in a page.** The card caps its own width.
- **One element per slot.** Two paragraphs in one slot need your own wrapper `<div>`.
- **No HTML comments** (`<!-- -->`) in anything that renders — Astro ships them
  verbatim. Strip them from every component you retheme. Notes go in frontmatter.
- **Cards are already flattened** (`isolate` on the card, `-z-10` on decorative
  layers, text classes on the card). Do not re-add a content wrapper `<div>`.
  When hoisting a text colour, **replace** the card's existing colour, don't add
  a second class of equal specificity.
- **`*FloatingBadge`**: if you use one, check the title badge has no
  `whitespace-nowrap` and that `pt-*` clears a 2-line wrapped title.
- **Emoji** go in their own `<span aria-hidden="true">`, never inside label text,
  never baked into a text prop.
- **No `href="#"`, no `onclick=`.** Back-to-top is `<a href="#top">`.
- **`alt` describes the picture** (see §4). Decorative repeats get `alt=""` +
  `aria-hidden="true"` on the wrapper.
- **Behaviour stays in `src/lib/`** — `isActivePath` from `../lib/nav`, never a
  hand-written `isActive`. No `define:vars`. No empty JS-filled feed containers.
- **JSON-LD only via `pageGraph()`**. Never type a domain, never build a URL with
  `+`. No `Review` / `AggregateRating` / `sameAs` / `address` / `email` nodes.
- **`<Image>`/`<Picture>` always get `widths` + `sizes`** describing how wide the
  image is DRAWN. Only the LCP image gets `loading="eager" fetchpriority="high"` —
  and that is MainLayout's hero, so everything else is `lazy`/`low`/`async`.
  Leave `quality={80}`; `tools/avif-quality-service.mjs` rescales AVIF on its own.
- **Meta `description`: 150–160 characters** for anything you write yourself
  (count characters, not bytes). The home page uses the brief's own Description
  line **verbatim**, unpadded.
- **Do not run `npm run build`.** The orchestrator runs it once, at the end.
